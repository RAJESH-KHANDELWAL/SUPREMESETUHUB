# Global Android Ecosystem

Canonical location for native Android application capabilities.

## Scope
- Android application modules, lifecycle integration, platform APIs, permissions, and device-specific adapters.
- Android build and release integration, coordinated with the repository's existing Android workflows.

## Boundaries
- Backend API implementation remains in `backend/global_ecosystem/global_android_ecosystem/`.
- Frontend-facing web integration remains in `frontend/global_ecosystem/global_android_ecosystem/`.
- Do not relocate existing Android source or workflow files until their actual locations and build references have been audited.
