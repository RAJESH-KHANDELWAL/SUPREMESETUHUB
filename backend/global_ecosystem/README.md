# GLOBAL ECOSYSTEM DIRECTORY

## Mission

Organize the Bharat-to-global landscape of domains, industries, people, organizations, products, vendors, platforms, standards, services and technologies in one extensible namespace.

Coverage spans Basic / Normal, Standard, Professional, Advanced, Expert, Enterprise / Industrial, Research, Frontier and Supreme / Long-horizon. "Supreme" is a future-facing taxonomy tier, not a claim that a capability exists or has been achieved.

## Geographic coverage

Bharat / India-first, followed by South Asia, Asia-Pacific, Middle East, Africa, Europe, North America, Latin America and the Caribbean, Oceania, and global cross-border interoperability. All coverage is subject to local laws, standards, licensing and jurisdictional requirements.

## Architecture ownership

- This directory owns domain taxonomy, catalog namespaces and domain-specific descriptive metadata.
- API owns public interfaces and transport contracts.
- CORE owns stable domain contracts and shared business rules.
- ENGINE owns orchestration, routing, tool execution and runtime workflows.
- DATABASE owns persistence schemas, migrations and data access.
- SECURITY / IDENTITY owns authentication, authorization, credentials, audit and policy enforcement.
- Provider SDK execution belongs in canonical provider integration layers through explicit, tested contracts.
- Do not duplicate runtime implementations, secrets, database logic or authentication code here.

## Status vocabulary

- `SCOPE_DEFINED`: domain is described in taxonomy.
- `CATALOGED`: represented in a catalog.
- `ROADMAP`: planned, not implemented.
- `RESEARCH`: exploratory work.
- `POLICY_GATED_SCOPE`: requires legal, safety, privacy or policy review.
- `IMPLEMENTED`: code exists and passes relevant tests.
- `INTEGRATED`: connected through a verified contract and integration test.
- `PRODUCTION_READY`: meets documented operational, security, reliability and compliance gates.

A directory, name, README or roadmap entry alone is not evidence of implementation.

## Integration principles

India-first localization with global interoperability; modular and provider-neutral contracts; evidence-based capability claims; least privilege; privacy by design; accessibility; human oversight for consequential actions; legal compliance; and reproducible tests with explicit operational-readiness criteria.
