# Global Domain Core — Naming Standard and Coverage

## Canonical ecosystem
- Display name: `GLOBAL DOMAIN CORE ECOSYSTEM`
- Ecosystem ID: `GLOBAL-DOMAIN-CORE-ECOSYSTEM`
- Parent ecosystem: `GLOBAL-CORE-ECOSYSTEM`
- Naming standard: `GLOBAL + SUBJECT + CORE ECOSYSTEM`
- Sector display names: generated as `GLOBAL <SUBJECT> CORE ECOSYSTEM`
- Sector IDs: generated as `GLOBAL-<SUBJECT>-CORE-ECOSYSTEM`

## Integrated sector registry
39 sectors are registered into the canonical catalog and parented to GLOBAL DOMAIN CORE ECOSYSTEM. Sector metadata is catalog-only; no sector implies a live provider connection or operational adapter.

## Provider inventory and coverage
Legacy directory inventory is retained. Expanded curated discovery registry contains 230 normalized unique provider references (232 raw name entries before normalization). This is a curated, non-exhaustive reference list; current product availability, accreditation, APIs, and live connectivity are not verified.
