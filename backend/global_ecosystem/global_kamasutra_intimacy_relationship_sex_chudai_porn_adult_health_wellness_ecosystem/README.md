- Adults 18+ only where required; apply a stricter age threshold when local law requires it.

- Protect identity, sensitive personal data and private communications through data minimization and retention controls.
- Enforce applicable local laws, platform rules, copyright, performer agreements and distribution rights.

Provider connections require explicit contracts, legal review and integration tests. Namespace presence does not mean a service, integration, provider or dataset is implemented or verified.
