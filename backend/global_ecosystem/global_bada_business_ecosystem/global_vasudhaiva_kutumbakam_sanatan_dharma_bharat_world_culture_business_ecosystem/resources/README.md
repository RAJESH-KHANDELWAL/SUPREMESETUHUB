# Resource registry

This directory is reserved for curated, permissioned and versioned resource indexes relevant to this business domain.

## Resource categories
- Official public institutions and cultural organizations.
- Community-approved directories and knowledge resources.
- Learning materials, bibliographies and research references.
- Creator, artisan and provider catalogs.
- Standards, licenses, policy documents and operational templates.
- Approved media assets with documented rights and attribution.

## Required metadata
For every resource, capture title, issuing organization/creator, canonical URL or repository path, resource type, language, geographic relevance, publication/update date, access date, rights/license, permission status, short relevance note and reviewer.

## Publication rules
- Prefer primary and authoritative sources.
- Do not invent URLs, affiliations, providers or endorsements.
- Verify external links and claims before publication and periodically thereafter.
- Respect copyright, privacy, access restrictions and community protocols.
- Keep secrets, personal data, credentials and private partner documents out of public indexes.

No external provider or institutional resource is asserted as connected merely because this directory exists.
