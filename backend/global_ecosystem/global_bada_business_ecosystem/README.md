# GLOBAL BADA BUSINESS ECOSYSTEM

Canonical root:
`backend/global_ecosystem/global_bada_business_ecosystem/`

This directory organizes the Global Bada Business Ecosystem, including provider-specific resources and the broader business-domain taxonomy.

## Main domains

- `business_ecosystem/` — general business taxonomy, business capabilities, resources, and domain indexes.
- `courses/` — course resource namespace.
- `events/` — event and webinar resources.
- `links/` — official and owner-provided destinations.
- `platform/` — platform identity and profile.
- `platform_resources/` — provider catalog and program snapshots.
- `products/` — product resource namespace.
- `referrals/` — referral metadata.
- `registration/` — registration resources.
- `course_resources/` — course-link directory.
- `global_network_marketing_direct_selling_business_ecosystem/` — direct-selling business families, including YOUTAG.
- `provider_resources/` — provider-supplied resource references.

## Architecture boundaries

API, CORE, ENGINE, DATABASE, AI, STORAGE, authentication and connection layers remain in their own architecture namespaces. Do not duplicate API transport logic, core business rules, engine orchestration, persistence schemas, credentials or live integrations here.

## Other independent ecosystems

- `backend/global_ecosystem/bada_business_ecosystem/` — standalone provider-specific Bada Business resources; remains separate.
- `backend/global_ecosystem/global_vasudhaiva_kutumbakam_sanatan_dharma_bharat_world_culture_ecosystem/` — cultural and civilizational domain; remains separate.

Provider URLs, program snapshots, course links, package details, pricing, commissions, event dates and promotional claims are reference data. They do not establish current availability, official API access, partnership, entitlement, accreditation, income guarantees or live connectivity. Verify current terms directly with the provider.
