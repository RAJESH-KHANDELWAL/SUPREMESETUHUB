# GLOBAL NETWORK MARKETING & DIRECT SELLING BUSINESS ECOSYSTEM

Parent namespace: `backend/global_ecosystem/global_bada_business_ecosystem/`

This ecosystem groups network marketing, direct selling, distributor/dealer, referral and service-distribution business domains.

## Child business ecosystem

- `global_youtag_business_ecosystem/` — the single YOUTAG business/company ecosystem.

### YOUTAG applications / platforms

- `global_youtag_business_ecosystem/youtag_wellness_app/`
- `global_youtag_business_ecosystem/youtag_recharges_app/`

YOUTAG WELLNESS and YOUTAG RECHARGES are two different apps/platforms of the same YOUTAG business/company. They are not separate companies or separate business ecosystems. Keep their app-specific functionality distinct while retaining one shared YOUTAG business identity.

## Layer ownership

This folder is a GLOBAL ECOSYSTEM namespace/index only. CORE owns identities and business rules; API owns endpoint contracts; ENGINE owns orchestration; DATABASE owns persistence; authentication and provider connections remain in their respective layers. No live vendor API or account connection is implied.
