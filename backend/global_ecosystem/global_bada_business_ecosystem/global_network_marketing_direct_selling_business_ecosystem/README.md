# GLOBAL NETWORK MARKETING & DIRECT SELLING BUSINESS ECOSYSTEM

Parent namespace:
`backend/global_ecosystem/global_bada_business_ecosystem/`

This ecosystem groups network marketing, direct selling, distributor/dealer,
referral and service-distribution business domains.

## Child ecosystem map

- `global_youtag_wellness_ecosystem/` — YOUTAG WELLNESS.
- `global_youtag_recharges_ecosystem/` — YOUTAG RECHARGES.

The child domains are separate. Product/wellness distribution and recharge
services must maintain separate catalogs, commercial terms, account flows,
and transaction boundaries.

## Layer ownership

This folder is a GLOBAL ECOSYSTEM namespace/index only. CORE owns identities
and business rules; API owns endpoint contracts; ENGINE owns orchestration;
DATABASE owns persistence; authentication and provider connections remain in
their respective layers. No live vendor API or account connection is implied.
