# NSFWINFRA ECOSYSTEM

Canonical NSFWInfra provider namespace in the Backend Global Ecosystem.

- `nsfwinfra.py`: server-side API connector; requires `NSFWINFRA_API_KEY` from the deployment secret manager.
- This connector submits image-generation requests only; it does not establish that the provider account is connected or that a request has been verified live.
- NSFWInfra is adult-content infrastructure. Any product exposure or execution must remain behind age, jurisdiction, consent, content-safety, authorization, and audit controls.
