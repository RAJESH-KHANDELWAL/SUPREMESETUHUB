# MICROSOFT AZURE SERVER ECOSYSTEM

Canonical provider namespace for Microsoft Azure within SUPREMESETUHUB GLOBAL SERVER.

- Provider identity: `microsoft`
- Existing adapter compatibility package: `../microsoft_server/`
- Service-family namespaces are catalog/contract boundaries, not proof of provider support or live connectivity.
- Provider-specific handlers must be explicitly configured and validate provider capabilities, credentials, authorization, and operation payloads.

## Service-family namespaces

- `microsoft_vpn_server_ecosystem/` — VPN SERVER (vpn-server)
- `microsoft_vps_server_ecosystem/` — VPS SERVER (vps-server)
- `microsoft_cloud_server_ecosystem/` — CLOUD SERVER (cloud-server)
- `microsoft_web_server_ecosystem/` — WEB SERVER (web-server)
- `microsoft_cloud_web_server_ecosystem/` — CLOUD WEB SERVER (cloud-web-server)
- `microsoft_dedicated_server_ecosystem/` — DEDICATED SERVER (dedicated-server)
- `microsoft_edge_server_ecosystem/` — EDGE SERVER (edge-server)
- `microsoft_application_server_ecosystem/` — APPLICATION SERVER (application-server)
- `microsoft_database_server_ecosystem/` — DATABASE SERVER (database-server)
