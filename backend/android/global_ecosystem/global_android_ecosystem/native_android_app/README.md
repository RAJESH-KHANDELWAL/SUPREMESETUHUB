# Native Android App

Canonical native Android Gradle project for Backend Global Android Ecosystem.

- Ecosystem root: `backend/android/global_ecosystem/global_android_ecosystem/`
- Native app project: `native_android_app/`
- Gradle app module: `native_android_app/app/`
- Release task: `:app:bundleRelease`
- Release artifact: `app/build/outputs/bundle/release/app-release.aab`

This project is owned by the Backend Android ecosystem. Keep its Gradle configuration,
Android manifest, Kotlin sources, resources, and ProGuard rules inside this directory.
