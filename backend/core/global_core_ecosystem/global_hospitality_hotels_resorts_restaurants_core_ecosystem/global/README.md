# Global hospitality geography

Global coverage is country-first and must support country-specific administrative models:
Country → State / Province / Region / Territory → District / County → Municipality → City / Town / Village → Locality → Street.

Maintain ISO 3166 country and subdivision identifiers where applicable, local-language names, transliterations, boundary/version dates, parent IDs, coordinates and provenance. Some countries do not publish or use every level; preserve the source country's actual model instead of forcing a single hierarchy.

Worldwide coverage must not be represented as complete until all country and subnational datasets have been sourced, licensed, imported and validated. Never fabricate hospitality venue listings or claim exhaustive street-level coverage without data evidence.
