# Hospitality category taxonomy

Canonical categories and subcategories for discoverability and classification:
- Accommodation: hotels, resorts, motels, inns, lodges, hostels, guest houses, homestays, serviced apartments, vacation rentals, heritage properties, eco-lodges, camps and glamping.
- Food and beverage: restaurants, fine dining, casual dining, family dining, cafes, coffee shops, bakeries, confectioneries, dhabas, food courts, QSR, takeaway and catering.
- Venues and events: banquet halls, wedding venues, convention centres, conference facilities and event spaces.
- Supporting facilities: kitchens, laundry, housekeeping, room service, concierge, parking, wellness/spa, recreation and accessibility services.

Category records should have stable IDs, parent IDs, multilingual labels, definitions, inclusion/exclusion rules and source/version metadata.
