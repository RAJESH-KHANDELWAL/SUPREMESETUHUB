# AbeloHost Domain Core

Provider identity and metadata contracts for AbeloHost within Global Domain Core.

- Provider ID: `abelohost`
- Source scope: Privacy-focused hosting reference; domain registrar/API support requires verification
- Official reference: https://abelohost.com/
- API package reference: `abelohost_domain_api_ecosystem/abelohost_domain_api_ecosystem.py`
- Status: `CORE_CATALOG_ONLY`

This package does not authenticate, connect to the provider, purchase or transfer domains, change DNS, issue certificates, or perform any other external action. API transport belongs to API; runtime belongs to ENGINE; persistence belongs to DATABASE; secrets and authorization belong to IDENTITY / SECURITY.
