# Global Digital Infrastructure, Telecommunications, Technology, IT, AI — Service, Work & Business CORE

Provider-neutral classification and governance layer for digital infrastructure, telecommunications, software, cloud, IT and AI services.

## Core modules
- catalog.py: ecosystem identity and parent references.
- domain_catalog.py: canonical service/work/business taxonomy.
- provider_registry.py: provider capability metadata.
- contracts.py: typed business context and engagement contracts.
- policy.py: lifecycle, evidence, approval and risk validation.
- service.py: classification and validation logic.
- orchestrator.py: health, inventory and dependency map.
- manager.py: canonical Python entry point and read-only 2,468 master-catalog bridge.
- manager.php: optional PHP 8+ metadata facade.
- tests/: executable behavior tests.

## Scope
Digital infrastructure; telecommunications; cloud, hosting and data centres; software and application engineering; IT operations and managed services; AI, data and automation; cybersecurity, privacy and trust; professional technical work; business operations and commercial services; service delivery and lifecycle management.

Provider manifests are taxonomy metadata only. They do not assert account ownership, live connectivity, certification, partnership, API access or production integrations.

This CORE classifies and validates metadata only. It does not execute work, deploy infrastructure, process payments, persist customer records, provide legal/security certification or connect to third-party APIs. Integrations require separately permissioned adapters and external secret management.

The master catalog at backend/GLOBAL_SUPREME_ECOSYSTEM_CATALOG.json remains read-only and is not modified by this ecosystem.
