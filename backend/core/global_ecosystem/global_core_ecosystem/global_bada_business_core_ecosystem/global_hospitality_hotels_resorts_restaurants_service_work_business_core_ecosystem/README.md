# Global Hospitality Hotels Resorts Restaurants Service Work Business Core Ecosystem

This is the service, work and business layer paired with the Hospitality CORE ecosystem.

## Coverage
- Hospitality business types: hotels, resorts, restaurants, cafes, dhabas, homestays, hostels, serviced apartments, catering, banquet and convention venues.
- Services: reservations, front office, guest relations, housekeeping, room service, food production, restaurant service, catering, concierge, laundry, maintenance, security, transport, wellness, events and facility management.
- Work and careers: owners, operators, managers, chefs, cooks, servers, stewards, receptionists, housekeeping teams, maintenance staff, sales, marketing, finance, HR, technology, consultants, contractors, freelancers, apprentices and training.
- Business operations: property setup, procurement, inventory, supplier networks, licensing/compliance references, quality, customer experience, distribution, revenue management, marketing, finance and multi-location operations.
- Geography: link every business/service/work record to the canonical country → state/region → district → city/town/village → locality/street geography in the paired CORE ecosystem.

## Boundary
Do not duplicate the canonical geographic taxonomy or core hospitality category registry. Reference the paired CORE ecosystem. Do not create fictional venue listings, job vacancies, contacts, ratings or live availability. Import real records only from verified, licensed sources with provenance.

## Required record provenance
Every imported record must retain a stable ID, source, source URL or dataset identifier, retrieval date, verification status, applicable geography ID and update history.
