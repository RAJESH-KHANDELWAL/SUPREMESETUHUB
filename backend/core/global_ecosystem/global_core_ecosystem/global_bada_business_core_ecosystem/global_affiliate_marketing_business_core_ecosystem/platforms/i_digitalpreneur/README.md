# iDigitalPreneur CORE ECOSYSTEM

**Canonical platform ID:** `I-DIGITALPRENEUR`  
**Parent:** GLOBAL AFFILIATE MARKETING BUSINESS CORE ECOSYSTEM  
**Layer:** CORE

This package owns iDigitalPreneur-specific identity boundaries and the adapter into the shared affiliate business contracts.

## Scope

- Preserve the platform identity independently from LeadsGuru and Millionaire Track.
- Validate platform-specific routing at the CORE boundary.
- Reuse parent affiliate policies for disclosures, terms URLs, program activation and event invariants.
- Delegate persistence through the injected repository contract.
- Keep all program terms, commission rules, eligibility, geography, fees and payout arrangements unverified until supported by current official evidence.

## Not implemented here

No provider API calls, authentication, account linking, tracking redirects, attribution transport, payout execution, settlement or credential storage. These belong to their respective API, ENGINE, DATABASE, STORAGE and application layers.

No commission percentage, referral reward, joining fee, eligibility condition or program status is assumed by this package.
