# GLOBAL INDEPENDENT FREELANCER REMOTE HYBRID PART TIME FULL TIME WORK FROM HOME GIG SERVICE WORK BUSINESS CORE ECOSYSTEM

**Parent:** `GLOBAL-BADA-BUSINESS-CORE-ECOSYSTEM`  
**Canonical path:** `backend/core/global_ecosystem/global_core_ecosystem/global_bada_business_core_ecosystem/global_independent_freelancer_remote_hybrid_part_time_full_time_work_from_home_gig_service_work_business_core_ecosystem/`

## Mission
Own the Bada Business-facing service-work and service-business capability classification for independent, freelance and gig work.

## Ownership boundaries
- Global Core owns the canonical work-model IDs and definitions: Freelancer, Remote, Hybrid, Part-Time, Full-Time, Work From Home and Gig.
- This Global Bada Business package owns the service-work and service-business classification.
- Work-model definitions are imported from the canonical Global Core package; they are not duplicated here.
- Jobs & Careers remains a separate employment and career classification domain.

## Layer boundaries
- CORE provides taxonomy, metadata, policy boundaries and discovery contracts.
- API owns external provider integrations and live listings.
- Engine owns execution, scheduling and dispatch.
- No live jobs, verified providers, payments or transactions are claimed by this CORE package.
