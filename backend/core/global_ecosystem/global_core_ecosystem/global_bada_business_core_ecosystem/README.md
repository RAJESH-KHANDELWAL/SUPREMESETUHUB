# GLOBAL BADA BUSINESS CORE ECOSYSTEM

Global Bada Business CORE owns business-domain capability contracts and child ecosystem classification. This repository currently contains the cultural service/work/business child package below.

## Child CORE packages

- `global_culture_service_work_business_core_ecosystem/` — cultural capabilities classified as SERVICE, WORK and BUSINESS; governance and validation only. Cultural domain knowledge remains owned by the Culture CORE source ecosystem.

## Layer boundaries

CORE provides domain contracts, capability classification, governance and discovery interfaces. Provider-owned facts and live listings must come from canonical resource ecosystems. CORE does not claim live jobs, providers, transactions, or connections unless independently verified.
