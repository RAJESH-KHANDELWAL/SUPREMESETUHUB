# Global Government & Private Jobs, Careers, Employee and Employment Core Ecosystem

A global, metadata-first taxonomy for public-sector and private-sector jobs, careers, employers, employees, workforce arrangements and employment lifecycle.

## Architecture
- domain_catalog.py: canonical employment domains and topics
- catalog.py: normalized inventory and classification vocabularies
- policy.py: privacy, equal-opportunity and source-quality guardrails
- service.py: taxonomy search and record validation
- manager.py: stable Python entry point
- manager.php: PHP metadata facade
- test_ecosystem.py: offline deterministic checks

This package does not claim live vacancies, employer verification, recruitment access, legal advice or external integrations. Government notices and jurisdiction-specific rules must be verified from official sources before being represented as current. The 2,468-entry master catalog remains the read-only planning reference.
