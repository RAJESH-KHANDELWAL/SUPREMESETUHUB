# Communication Provider Core Package

This package defines provider identity and Core-layer contracts only.

- Integration status: `CORE_CATALOG_ONLY`
- Live connection verified: `false`
- API transport and provider-specific adapters remain in the API/runtime layer.
- No credentials, network calls, message delivery, resource mutation or persistence are implemented here.

The ten responsibility folders separate authentication, capabilities, documentation, events, lifecycle, models, schemas, security, services and tests. Empty folders are structural placeholders until a reviewed implementation is added.
