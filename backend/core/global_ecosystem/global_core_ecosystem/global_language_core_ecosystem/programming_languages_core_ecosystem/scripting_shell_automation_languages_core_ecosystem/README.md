# SCRIPTING SHELL AUTOMATION LANGUAGES

Scripting, command shells, build languages and automation language taxonomy.

## Responsibilities
- Maintain language identity, aliases, paradigm and specification metadata.
- Track version, compiler/runtime, platform and support lifecycle references where available.
- Expose read-only catalog metadata to developer tooling, API and ENGINE consumers.

## Boundaries
- This CORE catalog does not install, execute or certify a language runtime.
- Build pipelines, code execution and provider integrations belong to their dedicated runtime boundaries.
- Status: `CORE_CATALOG_ONLY`; the domain is not claimed fully populated.
