# Global Domain Core — Expanded Coverage Update

## Coverage model
The previous **78 provider directory references** are retained as a legacy directory inventory. They are not a coverage limit or a claim of global completeness. The expanded registry now combines a broad curated provider-reference list and a sector taxonomy. Names are discovery references, not verification of current product availability, accreditation, API support, or live connectivity.

## New sector taxonomy
The taxonomy includes registry governance, gTLD and ccTLD registries, registrars/resellers, marketplaces, auctions/backorders, portfolio/lifecycle/transfers, WHOIS/RDAP, DNS hosting/resolvers/security/privacy/automation/routing/monitoring, nameserver infrastructure, TLS/ACME, brand protection/disputes/reputation, IDN, parking/redirect/email, deployment bindings, APIs, tenant security, data retention, observability, pricing and localization.

## Source policy
- ICANN Accredited Registrar List is a primary reference for gTLD registrar accreditation; it does not cover every ccTLD registry/operator or every domain service: https://www.icann.org/en/contracted-parties/accredited-registrars/list-of-accredited-registrars
- IANA Root Zone Database is a reference for delegated TLDs: https://www.iana.org/domains/root/db
- Provider references are curated and need source verification before being promoted to verified provider records.
- No external data dump was downloaded/imported in this change. Registry is deliberately marked curated and non-exhaustive.

## Readiness
Catalog-only. No provider adapters, API transport, credentials, registration/renewal/DNS write operations, or live status are implemented or verified by this inventory. Keep secrets external and write actions behind tenant authorization and explicit confirmation.
