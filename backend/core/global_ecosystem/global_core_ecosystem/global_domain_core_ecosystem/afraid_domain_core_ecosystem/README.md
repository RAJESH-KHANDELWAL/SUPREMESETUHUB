# FreeDNS afraid.org Domain Core

Provider identity and metadata contracts for FreeDNS afraid.org within Global Domain Core.

- Provider ID: `afraid`
- Source scope: Dynamic DNS and DNS hosting
- Official reference: https://freedns.afraid.org/
- API package reference: `afraid_domain_api_ecosystem/afraid_domain_api_ecosystem.py`
- Status: `CORE_CATALOG_ONLY`

This package does not authenticate, connect to the provider, purchase or transfer domains, change DNS, issue certificates, or perform any other external action. API transport belongs to API; runtime belongs to ENGINE; persistence belongs to DATABASE; secrets and authorization belong to IDENTITY / SECURITY.
