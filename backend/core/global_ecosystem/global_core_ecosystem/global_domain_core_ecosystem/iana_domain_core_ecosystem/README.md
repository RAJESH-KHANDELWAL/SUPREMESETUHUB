# IANA Root Zone Database Domain Core

Provider identity and metadata contracts for IANA Root Zone Database within Global Domain Core.

- Provider ID: `iana`
- Source scope: Root zone and TLD registry information
- Official reference: https://www.iana.org/domains/root/db
- API package reference: `iana_domain_api_ecosystem/iana_domain_api_ecosystem.py`
- Status: `CORE_CATALOG_ONLY`

This package does not authenticate, connect to the provider, purchase or transfer domains, change DNS, issue certificates, or perform any other external action. API transport belongs to API; runtime belongs to ENGINE; persistence belongs to DATABASE; secrets and authorization belong to IDENTITY / SECURITY.
