# GLOBAL DOMAIN CORE ECOSYSTEM
Provider-neutral domain/registrar/registry/DNS/TLS taxonomy and metadata governance.

- `catalog.py`: existing legacy directory inventory and 18 responsibility definitions.
- `sector_catalog.py`: expanded sector taxonomy.
- `provider_registry.py`: curated provider discovery reference list with explicit unverified/catalog-only status.
- `manager.py`: canonical manager.
- `manager.php`: PHP compatibility surface.

Provider references are not live adapters or proof of coverage. See `DOMAIN_IMPLEMENTATION_STATUS.md` for source and readiness limits.
