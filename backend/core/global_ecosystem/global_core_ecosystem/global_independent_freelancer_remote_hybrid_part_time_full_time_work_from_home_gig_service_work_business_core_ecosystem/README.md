# GLOBAL INDEPENDENT FREELANCER REMOTE HYBRID PART TIME FULL TIME WORK FROM HOME GIG SERVICE WORK BUSINESS CORE ECOSYSTEM

**Parent:** `GLOBAL-BADA-BUSINESS-CORE-ECOSYSTEM`  
**Canonical path:** `backend/core/global_ecosystem/global_core_ecosystem/global_independent_freelancer_remote_hybrid_part_time_full_time_work_from_home_gig_service_work_business_core_ecosystem/`

## Mission
Own the Bada Business-facing service-work and business capability classification for independent/freelance/gig work. This layer references the canonical Global Core work-model taxonomy; it does not create a second copy.

## Work models
- `FREELANCER` — Independent contract-based work
- `REMOTE` — Work performed remotely
- `HYBRID` — Combination of remote and on-site work
- `PART_TIME` — Part-time engagement
- `FULL_TIME` — Full-time engagement
- `WORK_FROM_HOME` — Work performed from home
- `GIG` — Task-based or short-term independent work

## Ownership and relationship
- Global Core owns the canonical work-model IDs and definitions.
- Global Bada Business owns service-work/business capabilities, service categories and commercial classification.
- The Bada Business package references the Global Core taxonomy by stable ecosystem ID; it does not duplicate canonical work-model records.
- Jobs & Careers remains a separate employment/career classification domain.

## Layer boundaries
- CORE provides taxonomy, metadata, policy boundaries and discovery contracts.
- API owns external provider integrations and live listings.
- Engine owns execution, scheduling and dispatch.
- No live jobs, verified providers, payments or transactions are claimed by this CORE package.
