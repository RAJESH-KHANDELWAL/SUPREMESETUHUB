# ATLASSIAN WORK MANAGEMENT AND PLANNING CORE ECOSYSTEM

**Parent:** ATLASSIAN CORE ECOSYSTEM

**Domain ID:** `WORK_MANAGEMENT_AND_PLANNING`

**Purpose:** Jira projects, issues, boards, sprints, workflows and planning metadata.

This domain package exposes read-only discovery and inventory through `manager.py` and `get_manager()`. It does not execute provider API calls, credential exchange, writes, persistence or jobs.
