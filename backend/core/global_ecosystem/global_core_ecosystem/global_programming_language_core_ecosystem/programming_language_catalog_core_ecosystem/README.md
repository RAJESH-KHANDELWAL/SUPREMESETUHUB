# PROGRAMMING LANGUAGE CATALOG CORE ECOSYSTEM

Canonical index for the global programming-language taxonomy, language families, aliases, standards references and catalog provenance.

## Responsibilities
- Maintain canonical language names, aliases and language-family relationships.
- Reference language specifications, versions, paradigms and implementation/runtime metadata.
- Record provenance and lifecycle status without claiming unverified compiler or runtime support.
- Expose read-only catalog metadata to the programming-language division.

## Boundaries
- Individual language records are added only when supported by authoritative specifications or clearly identified sources.
- Compiler, interpreter and runtime execution remain in their dedicated domain and ENGINE boundaries.
- No provider credentials, code execution or live integrations belong in CORE.

Status: `CORE_CATALOG_ONLY`; the catalog is extensible and is not claimed exhaustive.
