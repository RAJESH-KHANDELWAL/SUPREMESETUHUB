# GLOBAL PROGRAMMING LANGUAGE CORE ECOSYSTEM

A separate, dedicated **CORE ecosystem** for computer/programming languages and developer language technologies. It is a direct sibling of `global_human_language_core_ecosystem/` under `global_core_ecosystem/`.

## Coverage
- General-purpose, systems, scripting, shell and automation languages
- Web frontend, backend, mobile, embedded and IoT development
- AI/ML, data science, statistics and database query languages
- Functional, object-oriented, game development and smart-contract languages
- Markup, stylesheet, schema and data-serialization languages
- Compilers, interpreters, virtual machines and runtimes
- IDEs, editors, SDKs, language servers, standards, testing, quality and security
- Programming education, technical documentation and legacy enterprise language support
- Bharat and global programming-language communities and education

## Catalog policy
The directory taxonomy is not a claim that every language or runtime is implemented. Each language record should include canonical name, aliases, paradigm, versions, specification, runtime/compiler, platforms, license, support status and security lifecycle. Do not treat HTML/CSS/SQL/JSON as interchangeable with general-purpose programming languages; classify by language type.

## Tier model
Normal → Basic → Standard → Premium → Professional → Enterprise → Supreme. Tiers describe supported tooling, learning, governance and service levels; they do not imply that every language has a production runtime here.
