## Mission
Canonical Core registry for relationships, intimacy education, adult sexual wellness, reproductive-health domains, Kamasutra/traditional knowledge, lawful adult-media industry metadata, and related professional, technology and commerce ecosystems.

## Google Core-aligned architecture
- manager.py: stable read-only entry point.
- catalog.py: canonical registry of 62 existing child packages.
- domain_catalog.py: 12 responsibility domains and package classification.
- orchestrator.py: inventory, discovery and readiness summaries.
- service.py: public status contract.
- contracts.py: normalized metadata result contract.
- policy.py: age, consent, rights, privacy and professional-boundary policy.
- manager.php: PHP interoperability facade.
- PRODUCT_ECOSYSTEM_STANDARD.md: package ownership and layer boundaries.
- IMPLEMENTATION_STATUS.md: implementation and verification state.

Existing 62 child package names and paths are preserved. Child folders remain registered scaffolds until actual package files and integrations are implemented.

## Layer ownership
Core owns identity, taxonomy, capability metadata, policy and readiness. API owns provider transport and integrations. Storage/Database own persistence. Engine owns jobs and execution. Frontend owns consent UX and user workflows. CRM/Business owns customer and commercial operations.

## Safety
Only lawful adult contexts involving consenting adults are in scope. Minors, exploitation, trafficking, coercion, non-consensual intimate imagery and child sexual abuse material are prohibited. Age assurance, informed consent, rights verification, privacy, reporting and moderation controls are mandatory. Clinical diagnosis/treatment must remain with appropriately licensed professionals.

Registration does not prove legal eligibility, API availability, user authorization, provider account access, payment readiness or live connectivity.
