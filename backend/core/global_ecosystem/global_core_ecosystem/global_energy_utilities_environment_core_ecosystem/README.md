# Global Energy Utilities & Environment CORE

Canonical taxonomy for energy resources, generation, grids, storage, electricity access, water and wastewater utilities, waste, pollution, climate, biodiversity, sustainability, infrastructure, data and environmental governance.

Includes 40 domain definitions and Bharat / Global reference overlays. Global CORE owns canonical domain IDs; commercial services and business capabilities belong in the sibling Bada Business CORE. Master catalog at backend/GLOBAL_SUPREME_ECOSYSTEM_CATALOG.json is referenced read-only and is never mutated here.

Metadata only: no live grid dispatch, plant/dam/valve control, utility operation, energy trading, permit issuance or regulatory approval is implemented or implied.
