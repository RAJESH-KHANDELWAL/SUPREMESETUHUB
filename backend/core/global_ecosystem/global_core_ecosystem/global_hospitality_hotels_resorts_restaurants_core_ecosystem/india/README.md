# Bharat hospitality geography

Model the complete administrative and settlement hierarchy for all 28 States and 8 Union Territories, without assuming every state uses identical administrative levels.

Expected hierarchy (where applicable):
Country (IN) → State / Union Territory → Division → District → Sub-district / Tehsil / Taluka / Block / Mandal → Municipal corporation / municipality / Nagar Panchayat / Gram Panchayat → City / Town / Village → Ward / Locality / Mohalla → Street / Road / Lane.

Use official state/UT and district identifiers wherever published. Keep alternate spellings, local scripts, PIN codes and boundary versions as sourced attributes. Do not invent missing district, village, locality or street records. Actual street-level coverage requires authoritative datasets and ongoing updates.
