# BADA BUSINESS CORE — PHP CONTRACT

This directory mirrors the PHP contract boundary used by the Google CORE package.

`BadaBusinessCoreContract.php` validates and normalizes CORE result arrays for PHP 8+ consumers. It performs no network I/O, authentication, payment, registration submission or provider API calls.

The separate PHP adapter remains at:
`backend/php/global_ecosystem/global_php_ecosystem/bada_business_php_ecosystem/`
