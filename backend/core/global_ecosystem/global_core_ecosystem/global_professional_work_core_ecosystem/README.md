# Global Professional Work Core Ecosystem

This directory defines the global taxonomy and reference layer for professional work.

It covers professional occupations, independent practitioners, professional disciplines, qualifications, standards, ethics, career pathways, knowledge domains, and cross-border professional practice.

Commercial delivery, paid service operations, agencies, and business-provider workflows belong in the corresponding Global Bada Business ecosystem:
`global_professional_service_work_business_core_ecosystem`.

## Structure

- `professional_work/`: professional-work reference area and API ecosystem placeholder.
- `professional_work_domains.json`: initial domain taxonomy.
- `manager.py`: lightweight taxonomy access and validation helpers.

This is a taxonomy foundation, not a directory of verified professionals or a legal accreditation registry.
