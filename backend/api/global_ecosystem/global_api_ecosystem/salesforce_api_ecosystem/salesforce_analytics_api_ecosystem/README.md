# Salesforce Analytics and CRM Analytics API Ecosystem

## Scope
Reports, dashboards, analytics datasets, and supported query interfaces.

## Setup
Enable Analytics permissions, confirm report/dashboard access and org licensing, configure a Connected App and OAuth scopes, and use an API-enabled integration user.

## Status
Service-family scaffold only. Adapter implementation, production credential persistence, and live connection are not verified. Enforce tenant isolation, least privilege, rate limits, audit logs, and token revocation before production use.
