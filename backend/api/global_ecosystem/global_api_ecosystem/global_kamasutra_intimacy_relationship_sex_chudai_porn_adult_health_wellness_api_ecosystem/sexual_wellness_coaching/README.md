# Sexual Wellness Coaching

**Domain ID:** `sexual_wellness_coaching`  
**Package:** `sexual_wellness_coaching`  
**Parent ecosystem:** Kamasutra, Intimacy, Relationship, Adult Health & Wellness  
**Coverage:** Bharat + Global  
**Access classification:** Adults 18+; consent-first  
**Status:** Taxonomy scaffold only

## Scope
This folder owns the taxonomy vocabulary for sexual wellness coaching. It is maintained independently under the standalone Kamasutra ecosystem.

## Subdomains
- non-clinical adult education coaching
- wellness goal setting
- communication skills
- coach verification
- scope-of-practice boundaries

## Governance
- Adults 18+ only. No minors, exploitation, coercion, trafficking or non-consensual content.
- Clinical services require appropriately licensed professionals; non-clinical coaches must stay within their scope.
- Any adult media activity requires documented consent, age assurance, licensing and jurisdiction review.
- Do not store sensitive personal or clinical records in this taxonomy package.
- Entries are classification labels, not verified providers, live listings, medical advice or legal approval.
