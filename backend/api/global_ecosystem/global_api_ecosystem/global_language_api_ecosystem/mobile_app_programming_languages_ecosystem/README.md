# Mobile App Programming Languages

## Purpose
Kotlin, Java, Swift, Dart, JavaScript, TypeScript and cross-platform mobile development.

## Scope
- Separate software/programming-language ecosystem; human spoken and written languages remain catalogued in the existing language folders.
- India and global developer ecosystems, subject to licensing, standards and provider availability.
- Language specifications, compilers, interpreters, runtimes, frameworks, tooling, testing and documentation as relevant.
- Support tiers: Normal, Standard, Advanced, Premium, Enterprise and Supreme.

## Adult-industry software safeguards
Where this category supports adult-industry platforms, scope is restricted to lawful, consensual services for verified adults aged 18+ or the higher age required by local law. Design for age assurance, informed consent, privacy, performer/content rights, moderation, reporting and takedown. Exclude minors, coercion, trafficking, exploitation, non-consensual intimate imagery and unlawful content.

## Implementation status
This folder is an architecture and documentation scaffold, not a compiler, programming language runtime, SDK, provider connection or live integration. Working implementations require code, dependency and license review, security testing and maintenance.
