# Video and Frame.io APIs

Adobe API family catalog for SUPREMESETUHUB.

## Scope
Media collaboration, asset and review workflows through supported Frame.io or Adobe video APIs.

## Integration rules
- Use the shared Adobe OAuth provider and server-side secret store.
- Request minimum product-specific scopes and permissions.
- Validate organization, product profile, ownership and user authorization.
- Apply rate limits, timeouts, retries, audit logging and secret redaction.
- Claim only documented API capabilities.

## Status
Catalog/documentation scaffold only; not a completed live connector. Implement and test its API operations separately.
