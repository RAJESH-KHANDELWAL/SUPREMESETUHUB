# Company Classification Standards

Company-specific framework for legal form, ownership, control, group relationships, enterprise scale, legal status and jurisdictional mappings. This package defines taxonomy metadata and crosswalk slots; it does not imply certification, legal advice or government-system connectivity.

Package contract: `DOMAIN_ID`, `DOMAIN_NAME`, `ADULT_RESTRICTED`, `DEFAULT_DISCOVERY_ENABLED`, `SUBCATEGORY_IDS`, `list_subcategories()`.
