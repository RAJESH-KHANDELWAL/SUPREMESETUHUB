# GLOBAL TOOLS API ECOSYSTEM

Central home for tool records and tool-specific functionality across Bharat and the world.

## Endpoint
- `GET /global/tools/status`

The matching `global_tools_ecosystem/` folder and `global_tools_ecosystem.py` entry module live together in this package. Companies, platforms, services, and integrations are maintained in their own sibling GLOBAL API ECOSYSTEM packages, not duplicated here.
