# GLOBAL COMPANIES API ECOSYSTEM

Central home for company records and company-specific functionality across Bharat and the world, including agriculture, manufacturing, technology, retail, and other industries.

## Endpoint
- `GET /global/companies/status`

The matching `global_companies_ecosystem/` folder and `global_companies_ecosystem.py` entry module live together in this package. Platforms, tools, services, and integrations are maintained in their own sibling GLOBAL API ECOSYSTEM packages, not duplicated here.
