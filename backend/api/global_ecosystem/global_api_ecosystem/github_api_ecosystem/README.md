# GITHUB API ECOSYSTEM

Canonical provider-owned catalog for GitHub APIs, aligned with the Google, AWS, Apple, Adobe, DeepSeek and DigitalOcean provider-root naming convention.

## Scope
- REST and GraphQL APIs
- Repositories, branches, commits, files and code
- Issues, pull requests, reviews and discussions
- GitHub Actions workflows, runs, jobs and artifacts
- Apps, installations, authentication and permissions
- Webhooks, checks, releases and security-related APIs
