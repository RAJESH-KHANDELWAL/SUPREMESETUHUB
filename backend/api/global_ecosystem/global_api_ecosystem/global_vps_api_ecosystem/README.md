## Scope boundary

- VPS-specific operations belong here even when a provider also appears in GLOBAL CLOUD.
- GLOBAL CLOUD remains for broader cloud-platform and cloud-native APIs.
- Shared provider records may map to both CLOUD and VPS; family routing is category metadata, not a claim of live connectivity.
- All newly generated provider directories are catalog scaffolds until official API documentation, authentication, permissions, and live calls are verified.
- Store credentials in environment variables or a secrets manager. Never commit API keys or tokens.
