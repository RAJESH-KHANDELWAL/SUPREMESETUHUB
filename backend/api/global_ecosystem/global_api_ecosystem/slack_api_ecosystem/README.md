# Slack API Ecosystem

Provider catalog for Slack workspace and app APIs, including OAuth, users,
conversations, messages, files, events, webhooks, reactions, search and workflows.

## Status

This is a structured metadata catalog, not a live Slack connector. Live connectivity
requires a Slack app, an authorized workspace installation, appropriate OAuth scopes,
secrets stored outside source control, signature verification and tested API calls.

Official documentation: https://api.slack.com/web
