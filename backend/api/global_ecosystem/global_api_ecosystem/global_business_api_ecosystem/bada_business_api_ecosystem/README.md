# BADA BUSINESS API ECOSYSTEM

Provider link catalog for Bada Business in SUPREMESETUHUB.

## Canonical relationship

- This provider catalog is located under `GLOBAL BUSINESS API ECOSYSTEM`.
- Existing Bada Business product backend remains at:
  `backend/api/global_ecosystem/global_api_ecosystem/global_bada_business_api_ecosystem/`
- This directory does not replace, rename or duplicate that existing product API.

## What can be catalogued here

1. Official Bada Business website and platform pages.
2. Courses, learning programmes and course landing pages.
3. Products, services and digital offers.
4. Referral / affiliate links and campaign URLs.
5. Partner, master-distributor, reseller and business resources.
6. Support, help-centre and public documentation links.
7. Developer/API portal and OAuth documentation, only where official materials exist.

## Link registry

The `links/` directory contains the structured link registry. Add supplied URLs with a clear type, title, provenance, review status and optional campaign label. Do not mark a destination official until its domain/ownership has been checked.

### Link statuses
- `pending_review` — submitted by owner; not yet validated.
- `verified_official` — destination and official ownership checked.
- `active` — approved for use in the product.
- `retired` — no longer promoted.

## API connection boundary

This is currently a link catalogue, not a live provider integration. No public Bada Business API, OAuth endpoint, developer programme or partner API is asserted by this code. Only add a live API connector after official documentation, permitted access and credentials have been provided and reviewed.

## Security and affiliate transparency

- Never store passwords, OTPs, API keys, bank/payment credentials or private dashboard URLs in this catalog.
- Store only public destination URLs intended for sharing.
- Keep referral/affiliate disclosure visible wherever such links are presented.
- Prefer HTTPS and reject unsafe URL schemes.
- Preserve source and review metadata; do not scrape login-protected content.
