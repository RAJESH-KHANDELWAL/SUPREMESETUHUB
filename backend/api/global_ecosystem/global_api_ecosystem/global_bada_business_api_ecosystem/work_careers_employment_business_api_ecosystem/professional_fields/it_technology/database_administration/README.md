# Database Administration

Database Administration is a professional subcategory within **IT & Digital Technology**. It groups related occupations and specialist work under a stable taxonomy identifier.

- Parent field: `it_technology`
- Subcategory ID: `database_administration`
- Parent API Ecosystem: `IT_TECHNOLOGY_PROFESSIONAL_FIELD_API_ECOSYSTEM`
- Subcategory API Ecosystem: `IT_TECHNOLOGY_DATABASE_ADMINISTRATION_PROFESSIONAL_SUBCATEGORY_API_ECOSYSTEM`

This is a classification resource only. It does not verify vacancies, employers, credentials, professional registration or legal eligibility. Employment-context dimensions remain separately classified through the existing Work & Careers categories.
