# Data Science Analytics

Data Science Analytics roles, occupations and specialist work within IT & Digital Technology.

This subcategory has its own package folder and stable identifiers. Its taxonomy is exposed through the shared Professional Fields API Ecosystem; a separate API router is not added unless this subcategory later needs independent operations, data ownership or integration.

## Classification boundaries
- This is a professional/occupation classification, not an employer-sector or work-arrangement classification.
- Roles may also be tagged as government, private-sector, corporate, public-sector, local, international, remote, hybrid, full-time, part-time, contract or other applicable Work & Careers dimensions.
- Credentials, statutory registration, active vacancies and employer legitimacy require separate evidence and are not implied by this taxonomy.
