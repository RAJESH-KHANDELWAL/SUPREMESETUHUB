# Warehousing & Inventory

Warehouse, inventory and distribution occupations.

- Parent professional field: `transport_logistics` — Transport & Logistics
- Stable subcategory ID: `warehousing_inventory`
- API Ecosystem ID: `TRANSPORT_LOGISTICS_WAREHOUSING_INVENTORY_PROFESSIONAL_SUBCATEGORY_API_ECOSYSTEM`

This child package classifies professional occupation only. Employment sector, geography, work arrangement, schedule, engagement type and seniority remain independent dimensions in the existing Work & Careers categories. This taxonomy does not verify vacancies, employers, credentials, professional registration or legal eligibility.
