# Seasonal Jobs

Dedicated taxonomy for roles linked to recurring or time-limited seasonal demand.

## Tracks
- `agriculture_harvest_jobs` — Agriculture and Harvest Jobs: Seasonal agricultural, crop, harvest and allied work.
- `tourism_and_hospitality_seasonal` — Tourism and Hospitality Seasonal Jobs: Seasonal roles driven by tourism, travel and hospitality demand.
- `retail_festival_seasonal` — Retail and Festival Seasonal Jobs: Retail, sales and support roles tied to festival or holiday periods.
- `logistics_peak_seasonal` — Logistics Peak-Season Jobs: Warehouse, delivery and logistics roles for documented peak periods.
- `summer_and_winter_seasonal` — Summer and Winter Seasonal Jobs: Roles tied to a stated summer, winter or other recurring season.

## API
- `GET /seasonal-jobs/status`
- `GET /seasonal-jobs/tracks`
- `GET /seasonal-jobs/tracks/{track_id}`
- `GET /seasonal-jobs/search?q=...`

Record the season, duration, location, employer and source listing where available. Seasonality does not determine legal employment status. Taxonomy only; no live vacancies are asserted.
