# Digital Marketing

## Scope
Digital campaign execution, content distribution, lead generation and performance measurement.

## Independent work catalogue
This specialization owns its work-type catalogue in `work_types.py`. Each work type has a stable ID, a clear deliverable-oriented name and an explicit scope. The package exposes its own model, catalogue, service facade, API router, schema, validator and tests.

## Work types
1. **Digital campaign planning** — Digital campaign planning.
2. **Performance marketing operations** — Performance marketing operations.
3. **Email marketing campaigns** — Email marketing campaigns.
4. **Content marketing** — Content marketing.
5. **Lead generation campaigns** — Lead generation campaigns.
6. **Marketing analytics and reporting** — Marketing analytics and reporting.
