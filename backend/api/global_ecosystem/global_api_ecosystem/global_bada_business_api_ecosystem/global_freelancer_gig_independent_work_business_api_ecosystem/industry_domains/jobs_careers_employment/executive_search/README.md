# Jobs & Careers Industry Category

Independent API package for one canonical Jobs, Careers & Employment industry category. IDs and subcategory membership are resolved from the domain catalogue; that catalogue remains the source of truth.

Modules: `categories.py` (binding/integrity), `models.py`, `catalog.py`, `schemas.py`, `services.py`, `routes.py`, `validators.py`, and `tests/`.

Taxonomy only: no live vacancies, verified employers, recruitment outcomes, legal eligibility or compliance approval are implied.
