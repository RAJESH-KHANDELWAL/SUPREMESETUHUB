# Executive Jobs

Dedicated taxonomy for senior leadership, executive management and board-level roles.

## Tracks
- `director_and_vp_roles` — Director and Vice-President Roles: Senior functional or business-unit leadership roles with documented remit.
- `c_suite_roles` — C-Suite Roles: Chief executive, finance, technology, operating and other executive leadership roles.
- `managing_director_roles` — Managing Director Roles: Managing director positions with legal entity and governance responsibilities verified.
- `board_and_non_executive_roles` — Board and Non-Executive Roles: Board appointments and non-executive director roles; distinguish employment from governance appointments.
- `business_unit_executive_roles` — Business-Unit Executive Roles: Executive leadership of a defined business unit, region or operating division.

## API
- `GET /executive-jobs/status`
- `GET /executive-jobs/tracks`
- `GET /executive-jobs/tracks/{track_id}`
- `GET /executive-jobs/search?q=...`

Capture role remit, reporting line and governance responsibilities when disclosed. Do not infer board appointment or fiduciary authority from a title alone. Taxonomy only; no live vacancies are asserted.
