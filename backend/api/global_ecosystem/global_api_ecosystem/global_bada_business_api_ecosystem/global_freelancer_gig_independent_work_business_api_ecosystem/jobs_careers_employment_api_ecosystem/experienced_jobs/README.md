# Experienced Professional Jobs

Dedicated taxonomy for roles requiring relevant prior experience or specialist capability.

## Tracks
- `mid_level_professional_roles` — Mid-Level Professional Roles: Roles requiring established professional experience and independent delivery.
- `senior_specialist_roles` — Senior Specialist Roles: Roles requiring deep specialist expertise and a demonstrated track record.
- `technical_expert_roles` — Technical Expert Roles: Experienced technical roles with defined domain expertise and responsibility.
- `team_lead_roles` — Team Lead Roles: Roles with responsibility for coordinating or supervising a team.
- `career_progression_roles` — Career Progression Roles: Experienced roles representing a documented step up in scope or responsibility.

## API
- `GET /experienced-jobs/status`
- `GET /experienced-jobs/tracks`
- `GET /experienced-jobs/tracks/{track_id}`
- `GET /experienced-jobs/search?q=...`

Capture required experience as stated by the employer. Do not infer seniority from a title alone. Taxonomy only; no live vacancies are asserted.
