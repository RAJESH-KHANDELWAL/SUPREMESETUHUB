# Private Jobs

Dedicated taxonomy for jobs with privately owned employers: private companies, small and medium businesses, proprietorships, partnership firms, startups, family-owned businesses, professional firms, and private retail or service businesses.

Private ownership is separate from corporate legal structure. A privately owned corporation may appear in both Private Jobs and Corporate Jobs. Each vacancy must retain legal employer identity and ownership evidence. This package does not provide live vacancies, employer verification, or legal eligibility decisions.
