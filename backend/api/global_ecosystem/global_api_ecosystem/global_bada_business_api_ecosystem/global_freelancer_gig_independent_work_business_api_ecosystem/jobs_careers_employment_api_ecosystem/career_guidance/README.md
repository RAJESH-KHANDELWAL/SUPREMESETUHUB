# Career Guidance

Dedicated taxonomy for career information, counselling, assessment, mentoring and planning services. These are services, not vacancies.

## Tracks
- `career_counselling` — Career Counselling: One-to-one or group career counselling services with provider qualifications stated where relevant.
- `career_assessment` — Career Assessment: Assessment services supporting career exploration; describe tools and limitations accurately.
- `career_coaching` — Career Coaching: Coaching services supporting career goals, planning and professional development.
- `career_mentoring` — Career Mentoring: Mentoring relationships connecting learners or professionals with experienced practitioners.
- `education_and_career_planning` — Education and Career Planning: Guidance connecting education choices, skills development and career pathways.

## API
- `GET /career-guidance/status`
- `GET /career-guidance/tracks`
- `GET /career-guidance/tracks/{track_id}`
- `GET /career-guidance/search?q=...`

Do not claim accreditation, guaranteed outcomes or professional credentials without evidence. Keep providers and service offers separate from vacancy records.
