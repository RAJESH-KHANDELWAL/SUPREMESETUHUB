# Real Estate & Facilities

Property sales, valuation, development, brokerage, facilities and property operations.

This field has a dedicated taxonomy package. Its subcategory IDs are defined in `categories.py` and exposed through the shared Professional Fields API Ecosystem. The child subcategory folders are independently documented; separate API routers will be introduced only when independent operations or data integrations are justified.

Employment sector, geography, work arrangement, engagement type and seniority remain separate classification dimensions from professional occupation.
