# IT & Digital Technology

Technology roles across software, data, infrastructure, security and digital systems.

## Package structure
- `categories.py`: canonical subcategory taxonomy for this field.
- `__init__.py`: stable package exports.
- Each child directory is an independently documented subcategory package.

## API Ecosystem
This field is addressable through the shared Professional Fields API Ecosystem at `/professional-fields/it_technology`. Child subcategories are listed at `/professional-fields/it_technology/subcategories` and detailed at `/professional-fields/it_technology/subcategories/{subcategory_id}`. A separate router is intentionally not duplicated for taxonomy-only child packages.

## Classification
This professional field can overlap with employer sector, geography, work arrangement, schedule, engagement type and seniority categories. Do not duplicate the same occupation merely because its employment context differs.
