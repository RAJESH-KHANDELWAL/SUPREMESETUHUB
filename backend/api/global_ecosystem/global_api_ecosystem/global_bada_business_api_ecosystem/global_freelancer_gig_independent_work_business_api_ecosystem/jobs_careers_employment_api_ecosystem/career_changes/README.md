# Career Change Opportunities

Dedicated taxonomy for employment pathways supporting occupational or industry transitions.

## Tracks
- `industry_transition_jobs` — Industry Transition Jobs: Roles supporting a move between industries with transferable skills.
- `occupation_change_pathways` — Occupation Change Pathways: Structured pathways into a different occupation, including documented retraining requirements.
- `reskilling_and_upskilling_roles` — Reskilling and Upskilling Opportunities: Roles or programmes linked to explicitly stated reskilling or upskilling.
- `second_career_opportunities` — Second-Career Opportunities: Employment pathways for people pursuing a new professional direction.
- `career_pivot_entry_roles` — Career-Pivot Entry Roles: Entry routes into a new field where prior transferable experience may be relevant.

## API
- `GET /career-changes/status`
- `GET /career-changes/tracks`
- `GET /career-changes/tracks/{track_id}`
- `GET /career-changes/search?q=...`

Show transferable skills and retraining requirements only when supported by a source. Do not promise placement or guaranteed employment. Taxonomy only; no live vacancies are asserted.
