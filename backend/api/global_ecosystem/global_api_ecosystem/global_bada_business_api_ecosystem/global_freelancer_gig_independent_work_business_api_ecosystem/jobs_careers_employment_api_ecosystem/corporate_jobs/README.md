# Corporate Jobs

Corporate Jobs classifies employment by employer organization type, not by ownership sector.

Tracks include private limited companies, public or listed companies, multinational corporations, corporate groups and conglomerates, large enterprises, head-office functions, corporate management and government-owned corporations.

A corporate employer can be privately owned, publicly listed, government-owned or jointly owned. The legal employer, corporate group, jurisdiction and ownership sector must be stored separately. Corporate form alone does not prove company size, stock listing, multinational status or legitimacy.

This package is a taxonomy and API contract only; it does not provide live vacancies, employer verification or legal eligibility decisions.
