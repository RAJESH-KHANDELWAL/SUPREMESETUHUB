# Retirement-Age Work Opportunities

Dedicated taxonomy for flexible work, consultancy and phased-retirement pathways.

## Tracks
- `phased_retirement_roles` — Phased-Retirement Roles: Roles with a documented reduced-hours or staged transition arrangement.
- `retired_professional_consulting` — Retired Professional Consulting: Consulting engagements drawing on prior professional experience.
- `part_time_experienced_roles` — Part-Time Experienced Roles: Part-time roles requiring established experience or specialist skills.
- `mentor_and_advisor_roles` — Mentor and Advisor Roles: Mentoring and advisory opportunities with defined scope and engagement terms.
- `flexible_expert_contracts` — Flexible Expert Contracts: Flexible fixed-term or contract engagements for experienced specialists.

## API
- `GET /retirement-work/status`
- `GET /retirement-work/tracks`
- `GET /retirement-work/tracks/{track_id}`
- `GET /retirement-work/search?q=...`

Do not assume age eligibility, pension effects or statutory retirement rules. Use inclusive, non-discriminatory descriptions. Taxonomy only; no live vacancies are asserted.
