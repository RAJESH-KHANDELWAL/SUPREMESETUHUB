# Job Placement Services

Dedicated taxonomy for services and programmes connecting candidates with employers. Placement services are not employment offers.

## Tracks
- `campus_placement_services` — Campus Placement Services: Institutional placement-cell services connecting students or graduates with employers.
- `graduate_placement_programmes` — Graduate Placement Programmes: Structured programmes supporting graduate recruitment and placement.
- `employment_agency_placements` — Employment Agency Placements: Candidate-employer matching services provided by employment agencies.
- `workforce_programme_placements` — Workforce Programme Placements: Placement pathways connected to public, nonprofit or workforce-development programmes.
- `professional_placement_services` — Professional Placement Services: Placement services for experienced or specialist professionals.

## API
- `GET /job-placement/status`
- `GET /job-placement/tracks`
- `GET /job-placement/tracks/{track_id}`
- `GET /job-placement/search?q=...`

Do not promise placement, salary or selection. Distinguish historical outcomes from guarantees and verify provider identity and service terms.
