# Legal Consulting

## Scope
Legal information and professional support tasks; legal advice and reserved activities require authorized counsel in the relevant jurisdiction.

## Independent work catalogue
This specialization owns its work-type catalogue in `work_types.py`. Each work type has a stable ID, a clear deliverable-oriented name and an explicit scope. The package exposes its own model, catalogue, service facade, API router, schema, validator and tests.

## Work types
1. **Legal research support** — Legal research support.
2. **Contract review support by qualified counsel** — Contract review support by qualified counsel.
3. **Policy and compliance documentation** — Policy and compliance documentation.
4. **Company and business documentation support** — Company and business documentation support.
5. **Legal transcription and formatting** — Legal transcription and formatting.
6. **Regulatory information research** — Regulatory information research.

## Boundaries
This package defines service and work classifications only. It does not claim that a gig, vacancy, client, provider, payment or licence is live or verified. Legal, accounting, transport, electrical and other regulated services must comply with the applicable jurisdiction and professional authorization requirements.
