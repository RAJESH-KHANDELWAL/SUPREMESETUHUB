# Data Analysis

## Scope
Data preparation, analysis, reporting, dashboards and decision-support deliverables.

## Independent work catalogue
This specialization owns its work-type catalogue in `work_types.py`. Each work type has a stable ID, a clear deliverable-oriented name and an explicit scope. The package exposes its own model, catalogue, service facade, API router, schema, validator and tests.

## Work types
1. **Spreadsheet cleaning and formatting** — Spreadsheet cleaning and formatting.
2. **Dashboard and KPI reporting** — Dashboard and KPI reporting.
3. **Business data analysis** — Business data analysis.
4. **SQL data extraction** — SQL data extraction.
5. **Data visualization** — Data visualization.
6. **Research and data validation** — Research and data validation.
