# Consensual Adult Couple Intimacy API Ecosystem

## Purpose
18+ relationship and intimacy education, consensual couples' wellbeing, marital intimacy education, sexual-health referrals and professional counselling discovery.

## Safety and compliance
Adults only; informed and ongoing consent; no coercion, exploitation, non-consensual imagery or minors. This package is a taxonomy scaffold, not a booking, matching or clinical service.

## Initial API scope
- Domain metadata and category discovery
- Search and filtering by jurisdiction and service type
- Provider capability metadata (no provider is represented as verified by this scaffold)
- Policy, consent, privacy and age-assurance requirements where applicable

## Implementation status
This directory is an API ecosystem scaffold and documentation package. It does not claim live provider integrations, age verification, identity verification, content hosting, payment processing, clinical care or legal approval.

## Integration
The global People, Work & Life catalog remains the central discovery index. This package is a distinct domain folder; route registration and production integrations require separate implementation and testing.
