# Public Transport Services

- Category ID: `public_transport_services`
- Parent ecosystem: Government, Public Services & Social Impact API Ecosystem
- Geographic scope: Bharat (India) and global markets
- Delivery channels: online, offline and hybrid
- Status: `taxonomy_scaffold`

## Scope

Municipal transport, public transit, road-related public services and transport authorities.

## Subcategories

- `municipal_transport`
- `public_transit`
- `road_services`
- `transport_authorities`

## Data ownership and safeguards

The canonical category definition and discovery API remain in the parent ecosystem's `catalog.py`, `service.py` and `routes.py`. This folder is the dedicated category documentation/package boundary; it does not duplicate provider records or create an unverified government directory. Government affiliation, eligibility, official status, tender validity, benefits, licences and service availability must be confirmed from the relevant official authority before publication or reliance.
