# Classification crosswalks

Crosswalks are separate versioned datasets. A mapping record must contain source classification/version/code, target classification/version/code, direction, relationship type (exact, broader, narrower, partial, candidate), method, evidence/source, confidence, reviewer and effective dates.

Do not generate a direct one-to-one crosswalk merely because labels look similar. Preserve many-to-many relationships and unmatched records. No official NIC 2025 ↔ ISIC Rev. 5 code-level crosswalk is claimed in this initial registry commit.
