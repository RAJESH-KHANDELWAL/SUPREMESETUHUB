# Digital Media, Creators & Platforms

## Scope
Websites, apps, social media, creators, streaming, publishing, advertising, e-commerce, SaaS, cloud, cybersecurity and content moderation.

## Shared discovery facets
Geography; language; accessibility; online/offline/hybrid delivery; individual/household/community/organization; provider verification; availability and applicable local rules.

## Status
Taxonomy/API scaffold only. No live global directory, provider verification, real-time availability or third-party integration is claimed.
