# Restricted 18+ Domain

## Scope
This package contains a restricted classification domain only. It is excluded from default discovery. Its presence does not authorize any activity, listing, provider or transaction.

## Package contract
The adjacent `__init__.py` exposes the stable domain ID, display name, restricted flag, default discovery flag and subcategory identifiers.

## Mandatory controls before activation
Any future activation requires jurisdiction-specific legal review, reliable age assurance, consent, privacy safeguards, moderation, access control and audit logging. A software flag is not age verification or legal authorization. Keep sensitive personal records outside this taxonomy package.

## Maintenance
Keep IDs synchronized with `global_world_catalog.py`; test default exclusion and access controls. Do not enable public discovery until all applicable legal, safety and privacy requirements have been reviewed.
