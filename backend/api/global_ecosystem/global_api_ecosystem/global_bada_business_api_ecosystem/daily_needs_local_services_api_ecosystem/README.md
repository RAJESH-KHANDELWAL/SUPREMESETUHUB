# Daily Needs & Local Services

## Purpose
Food; groceries; clothing; housing; utilities; repairs; cleaning; transport; childcare; eldercare; personal services; retail; delivery; local professionals; neighbourhood services; accessibility services.

## Discovery dimensions
- Person and life-stage context
- Country, state/province, city and neighbourhood
- Online, offline and hybrid delivery
- Individual, household, community and organization audiences
- Public, private, non-profit and cooperative providers
- Languages, accessibility and service availability


## Safeguards
Respect privacy, accessibility, inclusion, user safety and applicable local laws. Provide crisis or professional referrals where relevant; do not present directory metadata as professional advice or verified provider status.

## API package status
This is a taxonomy and integration scaffold. It does not claim a live global directory, verified providers, real-time availability, transactions, clinical services, legal approval or third-party API connectivity.

## Planned capabilities
- Stable category identifiers and metadata
- Search, filtering and jurisdiction-aware discovery
- Provider integration adapters with explicit verification status
- Localization, accessibility and privacy controls
- Audit logs, moderation and quality checks where appropriate
