# Global Agriculture, Food & Natural Resources API Ecosystem

Canonical home for the Agriculture, Food & Natural Resources taxonomy, domain packages, catalogs, models, schemas, services, routes and tests under Global Bada Business.

All domain folders and source files previously held in the former `agriculture_food_natural_resources/` package are consolidated here. This canonical package is the sole maintained location; the former root-level folder has been removed.

## Scope
Bharat and global agriculture, food systems, allied industries and natural resources. Coverage and verification status are defined by the individual domain packages; this taxonomy does not imply verified providers or live integrations.
