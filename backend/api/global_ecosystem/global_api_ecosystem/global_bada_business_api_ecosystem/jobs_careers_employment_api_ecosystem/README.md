# Jobs, Careers & Employment — Root API Ecosystem

Stable domain: `jobs_careers_employment`.

The maintained implementation is in `industry_api_ecosystems/jobs_careers_employment`. It contains 15 service categories and 60 subcategories, with category packages and nested subcategory packages. Use its catalog and routes as the source of truth; do not duplicate employment classification records.

This is a taxonomy/API foundation, not a live vacancy feed, verified employer directory, job application transaction system or guaranteed placement service.
