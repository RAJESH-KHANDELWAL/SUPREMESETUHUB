# Global Affiliate Marketing Business API Ecosystem

Central catalogue for affiliate marketing, referral commerce, publisher monetization, and performance-based partnerships in Bharat (India) and international markets.

## Structure
- `india/`: India-focused networks, advertiser programmes, cashback and referral platforms.
- `global/`: International networks, SaaS programmes, marketplaces, travel and digital-product programmes.
- `affiliate_models/`: commission and business models.
- `tracking_analytics/`: click, attribution, conversion and reporting concepts.
- `compliance_disclosures/`: jurisdictional compliance and disclosure references.
- `integrations/`: future API / feed / webhook adapter specifications.
- `schemas/`: provider-neutral data contracts.

## Accuracy and security rules
- Every provider folder is a catalogue record, not proof that a programme is currently open, available in every country, or accepting publishers.
- Verify official terms, regional eligibility, commissions, attribution windows, payout conditions and API access before implementation.
- Never promise guaranteed income, approval, or fixed commissions.
- Never commit passwords, API secrets, private tokens, or payout credentials.
- A catalogue record is not a live API connector. Live integrations require official documentation, secure credentials, implementation and tests.

Each provider record must eventually include official source URL, operator, market, eligibility, commission model, payout method/currency, restrictions, API status, last-checked date and verification status.

## Platform directory

Platform-specific API documentation is organized under `platforms/`: iDigitalPreneur, LeadsGuru and Millionaire Track. Keep their API contracts and credentials separate; official API availability must be verified independently.
