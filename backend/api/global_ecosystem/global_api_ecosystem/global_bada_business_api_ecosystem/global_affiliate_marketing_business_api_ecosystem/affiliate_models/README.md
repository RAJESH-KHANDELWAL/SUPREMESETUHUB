# Affiliate Business Models

- Pay per sale (PPS / CPS)
- Pay per lead (PPL / CPL)
- Pay per click (PPC / CPC), only where offered
- Pay per install (PPI / CPI)
- Recurring revenue share
- Fixed bounty / qualified action
- Cashback and rewards sharing
- Coupon and deal publishing
- Influencer / creator referrals
- Sub-affiliate / publisher referrals, only where permitted
- B2B partner, reseller and agency referrals

Record qualifying actions, attribution rules, exclusions, validation and reversal windows, commission basis and payment conditions.
