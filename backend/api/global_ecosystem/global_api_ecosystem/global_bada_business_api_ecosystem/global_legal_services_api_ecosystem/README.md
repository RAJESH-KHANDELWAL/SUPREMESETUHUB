# Global Legal Services API Ecosystem

A dedicated global entry point for Legal Services taxonomy and API-ecosystem documentation.

## Structure

- `legal_services/` — legal-services category definition and API boundary documentation.

## Ownership and implementation status

This folder owns the consolidated Legal Services taxonomy documentation. The moved documents define category scope, minimum provider data and verification safeguards; they do not constitute a working API, provider directory, legal-advice service or verified listing.

The former mixed professional coaching/consulting/education folder is not the canonical home for legal services. A production Legal Services implementation must be built and registered separately, with jurisdiction-aware provider verification and applicable professional licensing checks.

## Scope

- Civil, criminal, corporate, commercial and litigation service discovery
- Lawyers, legal practitioners and legal service providers, subject to jurisdiction-specific authorisation
- Legal documentation, opinions and representation only where permitted by applicable law

Never infer bar membership, licence, statutory authority or professional standing from a profile description. Show credential claims as unverified until checked against the relevant official register.
