# Legal Services

Canonical category ID: `legal_services`  
Canonical documentation package: `global_legal_services_api_ecosystem`

Civil, criminal, corporate, commercial and litigation service discovery.

## Data and compliance boundaries

This folder is a discovery taxonomy note. It does not establish that a provider exists, is available, is licensed, is enrolled, is accredited, is insured or is authorised to perform regulated work. Capture provider identity, service jurisdiction, evidence source, verification date and credential scope before displaying a verified status. Legal, tax, audit, company-secretarial, architectural, engineering and certification activities must follow the applicable jurisdiction's rules.

## API ownership

This folder is a legal-services taxonomy and API-boundary document. A dedicated legal-services runtime catalog and routes are not yet implemented here. Non-legal Professional Services (accounting support, consulting, HR, translation, BPO and documentation) are maintained separately in `global_professional_business_services_api_ecosystem`.
