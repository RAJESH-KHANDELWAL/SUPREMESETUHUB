# Legal, Consulting & Professional Services API Ecosystem

Consolidated discovery and documentation home for the `legal_consulting_professional_services` domain.

## Canonical implementation

The canonical maintained taxonomy and Python API package remains:
`industry_api_ecosystems/professional_legal_business_services`.

It owns the 12-category catalog, schemas, routes, service and tests. This API ecosystem folder contains navigation and documentation; it does not duplicate the Python implementation or provider records.

## Canonical API endpoints

- `GET /industries/professional-legal-business-services/status`
- `GET /industries/professional-legal-business-services/categories`
- `GET /industries/professional-legal-business-services/categories?q=...`
- `GET /industries/professional-legal-business-services/categories/{category_id}`

## Consolidated structure

- `categories/` — category descriptions and category API ecosystem notes for all 12 categories.
- `jobs/` — jobs and employment discovery.
- `business/` — business and professional service discovery.
- `india/` — India coverage notes.
- `global/` — international coverage notes.
- `coaches/`, `consultants/`, `advisors/` — professional role discovery.
- `access_tiers/normal/`, `access_tiers/supreme/` — access-tier documentation.

## Related education and training domain

- `education_learning_training/` — cross-domain navigation to the separately maintained Education, Learning & Training ecosystem.
- Canonical implementation: `industry_api_ecosystems/education_learning_training` (15 categories, service, routes, schemas and tests).
- Education-specific coaching, tutoring, corporate training, vocational skills, certifications and lifelong learning remain owned by that canonical education package. This folder links to it rather than duplicating it.

## Scope and limitations

This is a taxonomy and discovery documentation scaffold. It is not a legal advice service, law firm, CA/CS practice, regulator, government portal or professional licensing authority. No professional credentials, bar enrolment, certificate of practice, firm registration, accreditation, provider quality, client relationship or statutory eligibility is verified here. Applicable jurisdiction and current law must be checked through official sources and qualified professionals.

No separate live provider feed, legal case system, document filing, payment flow, appointment booking, licensing check or government integration is implemented by this documentation layer.
