# Legal, Consulting & Professional Services API Ecosystem

Discovery facade for the canonical `professional_legal_business_services` taxonomy package. The canonical package owns the 12-category catalog and Python API implementation; this facade documents legal/consulting-oriented navigation without duplicating records.

## Canonical API

- `GET /industries/professional-legal-business-services/status`
- `GET /industries/professional-legal-business-services/categories`
- `GET /industries/professional-legal-business-services/categories?q=...`
- `GET /industries/professional-legal-business-services/categories/{category_id}`

No separate live provider feed, legal case system, document filing, payment flow, appointment booking, licensing check or government integration is implemented by this compatibility documentation.

## Category navigation

See `categories/` for category scope and corresponding API ecosystem notes. Shared discovery dimensions are documented under jobs, business, India, global, coaches, consultants, advisors and access tiers.
