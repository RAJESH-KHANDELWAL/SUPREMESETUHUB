# Marketing, Media & Entertainment API Ecosystem

Stable ID: `marketing_media_entertainment`. A unified India + Global taxonomy for online, offline and hybrid marketing, advertising, media, entertainment and creative businesses.

## Coverage

- **Digital / online marketing:** SEO, search advertising, social media, content, email, affiliate, influencer, performance marketing and analytics.
- **Offline marketing:** print, outdoor, radio, television advertising, direct marketing, retail promotions, exhibitions and event campaigns.
- **Media & entertainment:** film, video, broadcasting, music, publishing, creator economy, gaming, live events, animation, media technology and talent services.
- **Channels:** online, offline and hybrid.

## Endpoints

- `GET /industries/marketing-media-entertainment/status`
- `GET /industries/marketing-media-entertainment/categories`
- `GET /industries/marketing-media-entertainment/categories?q=...`
- `GET /industries/marketing-media-entertainment/categories?channel=online|offline|hybrid`
- `GET /industries/marketing-media-entertainment/categories/{category_id}`

Taxonomy scaffold only. This package does not itself verify agencies, advertisers, publishers, creators, venues or service providers; nor does it provide campaign execution, ad account access, licensing, copyright clearance, talent representation, payments or live platform integrations.
