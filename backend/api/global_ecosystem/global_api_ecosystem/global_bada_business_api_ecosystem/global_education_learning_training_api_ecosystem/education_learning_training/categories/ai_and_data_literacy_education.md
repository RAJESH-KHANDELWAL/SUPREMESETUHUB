# AI, Generative AI & Data Literacy Education

Stable category ID: `ai_and_data_literacy_education`.

Covers AI fundamentals, Generative AI literacy, prompt design, machine-learning concepts, data literacy, responsible AI, AI safety education and applied AI tools for learners and educators.

This category is education and training, not AI product procurement, model hosting, scientific R&D or a claim that a learner is professionally certified. Learning material should explain model limitations, hallucinations, privacy, copyright, bias, safety and the need for human review.
