# Jobs & Careers Industry Subcategory

Independent API package for one subcategory belonging to its parent Jobs & Careers industry category. Its ID is checked against the canonical parent catalogue. No unsupported descriptions, live providers, vacancies, rates, credentials or compliance claims are invented.

Modules: `categories.py`, `models.py`, `catalog.py`, `schemas.py`, `services.py`, `routes.py`, `validators.py`, and `tests/`.

Taxonomy only; not a live job/provider listing or verification record.
