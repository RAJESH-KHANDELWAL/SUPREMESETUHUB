# Global Hotels, Resorts, Restaurants & Hospitality API Ecosystem

Canonical entry point for hotels, resorts, restaurants, dhabas, cafes, bakeries, catering, prepared-food delivery, accommodation, event venues and hospitality services across India and global markets.

The maintained implementation remains in `industry_api_ecosystems/food_hospitality_restaurants/`. This package exposes that implementation without duplicating its Python source.

## Classification boundary

- Food production, processing, agricultural food supply chains, food testing and food-safety compliance belong to Agriculture, Food & Natural Resources.
- Restaurants, dhabas, cafes, hotels, resorts, catering, prepared-food delivery, accommodation, event venues and restaurant operations belong here.
- Restaurant procurement, commercial kitchen equipment and restaurant technology remain here when they directly support hospitality operators.

## Compatibility

The former root-level `food_hospitality_restaurants/` path remains a compatibility entry point. Do not create a second implementation tree.

## Status

Taxonomy/API scaffold. This package does not imply verified businesses, live reservations, food ordering, payment processing, licences or provider integrations.
