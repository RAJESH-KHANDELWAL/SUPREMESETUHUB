# Affiliate Marketing Business API Ecosystem

Purpose: Organize affiliate marketing business models, affiliate networks, advertisers, publishers, offers, tracking, referrals, and commission information.

Scope:
- Affiliate networks and programs
- Advertiser and publisher relationships
- Campaign, offer, and referral classifications
- Click, conversion, and commission tracking concepts
- Country-specific compliance and disclosure references

Important:
- This folder is a structure/catalogue starting point, not a live affiliate network adapter or verified earnings service.
- Do not treat an offer or commission claim as guaranteed income.
- Verify official program terms, API documentation, tracking rules, and payout conditions before implementation.
- Add source, jurisdiction, last-checked date, and verification status to published program information.
