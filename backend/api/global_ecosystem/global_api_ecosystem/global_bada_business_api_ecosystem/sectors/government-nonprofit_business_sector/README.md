# Public Sector, Non-profit & Social Enterprise

- Sector ID: `government-nonprofit`
- Business models: offline, online, hybrid

## Business types
- public services
- NGOs
- charities
- foundations
- cooperatives
- social enterprises
- development organisations

## Implementation scope
This package is a sector taxonomy scaffold. Planned extensions include country-specific registries, local and global business profiles, verification, data sources, and sector-specific APIs. No live listings or API connectivity are implied by this scaffold.
