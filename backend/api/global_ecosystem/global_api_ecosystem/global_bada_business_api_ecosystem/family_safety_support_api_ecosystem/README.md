# Family Safety & Survivor Support

## Scope
Family safeguarding, child protection, abuse prevention, domestic/family violence support, survivor services, trauma-informed counselling and emergency referrals. Abuse is never classified as adult entertainment or sexual services.

## Discovery dimensions
Country/state/city/neighbourhood; online/offline/hybrid; language; accessibility; service type; provider verification; legal jurisdiction.

## Safeguards
Protect vulnerable people, prioritize safety and privacy, and use local safeguarding and emergency referral rules.

## Status
Taxonomy and API integration scaffold only. No live provider, booking, verification, content hosting or payment integration is claimed.
