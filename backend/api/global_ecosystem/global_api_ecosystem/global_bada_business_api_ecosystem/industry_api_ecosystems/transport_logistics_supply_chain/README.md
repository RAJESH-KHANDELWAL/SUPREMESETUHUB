# Transport, Logistics & Supply Chain API Ecosystem

Stable ID: `transport_logistics_supply_chain`. Includes 12 categories for India/global discovery.

Endpoints: `GET /industries/transport-logistics-supply-chain/status`, `GET /industries/transport-logistics-supply-chain/categories`, `GET /industries/transport-logistics-supply-chain/categories?q=...`, `GET /industries/transport-logistics-supply-chain/categories/{category_id}`.

Taxonomy scaffold only; live tracking, carrier onboarding and customs operations are not implemented.
