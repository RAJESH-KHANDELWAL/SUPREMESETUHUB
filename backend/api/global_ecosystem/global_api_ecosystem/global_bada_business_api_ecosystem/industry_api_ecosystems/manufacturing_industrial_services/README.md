# Manufacturing & Industrial Services API Ecosystem

Stable ID: `manufacturing_industrial_services`. Includes 11 top-level categories for India/global discovery. Mining, mineral extraction, ore processing, smelting and primary metals taxonomy is maintained separately in `mining_metals_minerals`.

Endpoints: `GET /industries/manufacturing-industrial-services/status`, `GET /industries/manufacturing-industrial-services/categories`, `GET /industries/manufacturing-industrial-services/categories?q=...`, `GET /industries/manufacturing-industrial-services/categories/{category_id}`.

Taxonomy scaffold only; supplier verification, factory audits and compliance workflows are not implemented.
