# Retail, E-commerce & Consumer Goods API Ecosystem

Stable ID: `retail_ecommerce_consumer_goods`. Includes 12 top-level taxonomy categories for India and global discovery across online, offline and hybrid channels.

Endpoints: `GET /industries/retail-ecommerce-consumer-goods/status`, `GET /industries/retail-ecommerce-consumer-goods/categories`, `GET /industries/retail-ecommerce-consumer-goods/categories?q=...`, and `GET /industries/retail-ecommerce-consumer-goods/categories/{category_id}`.

This is a taxonomy scaffold, not a verified seller directory, live product feed, payment gateway or fulfilment service.
