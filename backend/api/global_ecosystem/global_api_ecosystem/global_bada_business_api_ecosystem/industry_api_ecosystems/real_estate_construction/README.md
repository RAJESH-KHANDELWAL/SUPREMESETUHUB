# Real Estate & Construction API Ecosystem

Stable ID: `real_estate_construction`. Includes 12 top-level taxonomy categories for India and global discovery across online, offline and hybrid channels.

Endpoints: `GET /industries/real-estate-construction/status`, `GET /industries/real-estate-construction/categories`, `GET /industries/real-estate-construction/categories?q=...`, and `GET /industries/real-estate-construction/categories/{category_id}`.

This is a taxonomy scaffold, not a verified provider directory, property listing feed, legal opinion, valuation or transaction service.
