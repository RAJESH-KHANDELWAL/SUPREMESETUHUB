# Adult Sexual Health & Medicine — API Ecosystem

Domain: `healthcare_life_sciences`
Category: `adult_sexual_health_and_medicine`

## Intended API resources
- Category metadata and subcategory discovery
- Provider/service directory records with provenance and verification status
- Jurisdiction and licensing metadata
- Consent, privacy and eligibility policy references where applicable
- Jobs and business listings only after source verification

## Data contract requirements
Every provider/service record should carry a stable ID, official source URL, jurisdiction, verification state, last-verified timestamp and applicable licence/credential references. Do not expose patient, donor or other sensitive personal data.

## Operational status
Documentation only. No live provider feed, donor matching, clinical workflow, booking, diagnosis, payment or production integration is implemented by this folder.

## Compliance gate
No explicit pornography or exploitative material. Provider records must show credentials, jurisdiction, service scope and verified source; never imply diagnosis or treatment from a directory listing.
