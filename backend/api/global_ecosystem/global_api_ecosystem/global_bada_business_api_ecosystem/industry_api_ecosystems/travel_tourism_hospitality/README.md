# Travel, Tourism & Hospitality API Ecosystem

Stable ID: `travel_tourism_hospitality`. Includes 12 top-level categories for India/global discovery.

Endpoints: `GET /industries/travel-tourism-hospitality/status`, `GET /industries/travel-tourism-hospitality/categories`, `GET /industries/travel-tourism-hospitality/categories?q=...`, `GET /industries/travel-tourism-hospitality/categories/{category_id}`.

Taxonomy scaffold only; live availability and booking are not implemented.
