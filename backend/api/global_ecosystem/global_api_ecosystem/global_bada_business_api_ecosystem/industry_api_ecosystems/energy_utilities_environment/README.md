# Energy, Utilities & Environment

Domain taxonomy package for the Global Bada Business Industry API Ecosystems.

- Coverage labels: India and global
- Channels: online, offline and hybrid
- Categories: 12
- Status: `taxonomy_scaffold`

## Endpoints

- `GET /industries/energy-utilities-environment/status`
- `GET /industries/energy-utilities-environment/categories`
- `GET /industries/energy-utilities-environment/categories?q=...`
- `GET /industries/energy-utilities-environment/categories/{category_id}`

This package defines a discovery taxonomy only. It does not claim live listings, provider verification, government endorsement, professional licensing, regulatory approval, or quality certification. Integrations and verification workflows must be implemented separately.
