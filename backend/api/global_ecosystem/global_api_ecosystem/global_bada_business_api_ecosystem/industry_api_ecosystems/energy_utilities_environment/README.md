# Energy, Utilities & Environment API Ecosystem

Independent industry domain. The existing 12-category catalog and API routes remain the maintained implementation.

## Separate directories
- categories/: one file per energy, utilities or environment category
- jobs/: sector-specific roles and vacancies taxonomy
- business/: energy companies, utility providers and environmental service businesses
- india/: Bharat-specific policy, regulators, utilities and market references
- global/: country-specific energy and environment systems
- coaches/, consultants/, advisors/: distinct professional service directories
- access_tiers/normal/, supreme/, adult_18_plus/: separate access classifications

## Existing endpoints
- GET /industries/energy-utilities-environment/status
- GET /industries/energy-utilities-environment/categories
- GET /industries/energy-utilities-environment/categories?q=...
- GET /industries/energy-utilities-environment/categories/{category_id}

## Scope and limitations
This is a taxonomy scaffold, not live utility coverage, verified company listings, job vacancies, provider integration, regulatory approval or professional certification. Verify sources, licenses, safety requirements and jurisdiction-specific rules before publishing records. Adult 18+ is a separate classification only; it is not relevant to energy service eligibility and does not bypass law, safety or privacy controls.
