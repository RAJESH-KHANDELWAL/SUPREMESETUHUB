# Mining, Metals & Minerals

12-category taxonomy for mineral and metals sector discovery. Status: `taxonomy_scaffold`.

Endpoints: `GET /industries/mining-metals-minerals/status`, `GET /industries/mining-metals-minerals/categories`, `GET /industries/mining-metals-minerals/categories?q=...`, `GET /industries/mining-metals-minerals/categories/{category_id}`.

No live mineral reserve, mining lease, operating permit, supplier or environmental compliance data is included.
