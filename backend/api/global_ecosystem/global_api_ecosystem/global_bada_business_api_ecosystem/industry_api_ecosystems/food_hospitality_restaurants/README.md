# Food, Hospitality & Restaurants API Ecosystem

Stable domain identifier: `food_hospitality_restaurants`.

## Scope
India and global taxonomy for restaurants, food services, beverages, catering, delivery, accommodation, venues, food supply, restaurant technology and food safety.

## Existing API
The maintained implementation remains in this directory. Preserve its Python package, catalog, routes, schemas, service and tests. Existing API endpoints and implementation are not replaced by this directory scaffold.

## Structure
Each of the 12 catalog categories has its own directory and README under `categories/`. Shared directories cover jobs, businesses, India, global, coaches, consultants, advisors, API documentation and access tiers.

## Limitations
These folders are taxonomy/documentation scaffolds, not live restaurant listings, job feeds, reservations, food-ordering systems, payment integrations or verified licences. Provider verification, FSSAI and other applicable local compliance, food safety, privacy, payments and production API integrations require separate implementation and testing.
