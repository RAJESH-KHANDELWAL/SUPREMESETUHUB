# Hotels, Resorts, Restaurants & Hospitality

Taxonomy package for India/global discovery. Active catalog categories: 11. Status: `taxonomy_scaffold`.

## Scope
Hotels, resorts, restaurants, dhabas, cafes, bakeries, catering, prepared-food delivery, food trucks, institutional dining, accommodation, banquet venues, restaurant procurement and restaurant technology.

## Food classification boundary
Food production, food processing, agricultural food supply chains, food testing, food hygiene and food-safety compliance belong to Agriculture, Food & Natural Resources. The former `food_safety_quality` category is removed from this active hospitality catalog and classified under Agriculture & Food. Restaurant suppliers, commercial kitchens and food equipment remain here when they directly serve hospitality operators.

## Endpoints
- `GET /industries/food-hospitality-restaurants/status`
- `GET /industries/food-hospitality-restaurants/categories`
- `GET /industries/food-hospitality-restaurants/categories?q=...`
- `GET /industries/food-hospitality-restaurants/categories/{category_id}`

This taxonomy does not represent live listings, provider verification, reservations, food ordering, food-safety certification or regulatory approval.
