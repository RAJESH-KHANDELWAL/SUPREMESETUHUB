# Digital Infrastructure & Telecommunications API Ecosystem

Purpose: Build a Bharat-wide and global catalogue for digital infrastructure and telecommunications, covering jobs, businesses, services, providers, and infrastructure categories.

Existing API status and endpoints are maintained in the package implementation. This remains a taxonomy scaffold, not a live network map, verified job board, business registry, carrier integration or infrastructure certification.

## Main sections
- `jobs/`: roles, skills, employers, vacancies and career pathways. A listing is not proof that a vacancy or employer is genuine.
- `business/`: telecom, internet, data-centre, cloud and infrastructure businesses and service providers.
- `india/`: India-specific categories, jurisdictions, standards and source references.
- `global/`: country and region categories with jurisdiction-aware references.
- `access_tiers/`: `normal/`, `supreme/`, and `adult_18_plus/` policy-separated catalogues. Adult content must be lawful, age-restricted where required, and separately moderated; it must not be mixed into general discovery.

## Important boundaries
Add source, jurisdiction, last-checked time, verification status and moderation state before publishing records. Do not imply that an unverified company, job, coverage claim or service is genuine.
