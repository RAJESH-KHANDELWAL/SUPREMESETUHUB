# Sexual & Reproductive Healthcare

Independent domain folder in the standalone Kamasutra / Adult Sexual Health & Wellness API Ecosystem.

**Coverage:** Bharat + Global World | **Classification:** adult-only (18+) where applicable | **Status:** taxonomy scaffold.

## Subdomains
- sexual health education
- reproductive health
- fertility and conception
- STI information and clinical referrals
- diagnostics and telehealth

Use lawful, consensual, age-assured and privacy-preserving workflows. Clinical care requires licensed professionals. No minors, exploitation, trafficking, coercion or non-consensual content.
