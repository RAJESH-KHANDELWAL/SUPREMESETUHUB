# Global Payment Business API Ecosystem

Central home for payment platforms and payment-service providers used across Bharat and the global market.

## Provider packages
- PayPal
- Stripe
- Epoch
- Paxum
- Segpay
- Verotel
- CCBill

## Scope
Payment gateways, merchant accounts, payment processing, checkout, recurring billing, payout and settlement capabilities, supported markets, fees, currencies, compliance references and official API documentation.

## Ownership
This folder is nested under Global Finance, Banking & Insurance. Payment providers are not separate top-level business ecosystems. Banks, lending, insurance, investment and accounting remain in their respective Finance categories.

## Verification
A folder or provider reference does not prove current service availability, API access, regulatory authorization, pricing, or country eligibility. Record official source, country, checked date, API documentation status and live-connection status separately. Never store API secrets or payment credentials in taxonomy files.
