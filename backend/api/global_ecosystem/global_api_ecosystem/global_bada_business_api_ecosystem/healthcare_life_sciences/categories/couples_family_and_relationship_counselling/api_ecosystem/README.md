# Couples, Family & Relationship Counselling — API Ecosystem

Domain: `healthcare_life_sciences`
Category: `couples_family_and_relationship_counselling`

## Intended resources
- Qualified counsellor and therapy-service discovery
- Couples, marital and non-sexual family counselling categories
- Credential, jurisdiction and verification metadata
- Privacy, consent and safeguarding policy references

## Safeguards
Family, relatives and friends are included only in non-sexual counselling and social-support contexts. Exclude sexualized family/relative content, minors, coercion and exploitation. Protect client confidentiality and do not expose counselling records.

## Operational status
Documentation scaffold only. No live provider feed, appointment booking, counselling records, payment or production integration is implemented.
