# Couples, Family & Relationship Counselling

Category ID: `couples_family_and_relationship_counselling`

## Scope
Professional couples therapy, marital counselling, non-sexual family therapy, relationship support and intimacy counselling for consenting adults.

## Subcategories
- `couples_therapy`
- `marital_counselling`
- `family_therapy`
- `relationship_and_intimacy_counselling`

## Data and safety requirements
Family, relatives and friends are included only in non-sexual counselling and social-support contexts. Exclude sexualized family/relative content, minors, coercion and exploitation. List only appropriately qualified counsellors and services with source and jurisdiction verification.

This folder is a taxonomy scaffold; it does not establish live integrations or verified providers.
