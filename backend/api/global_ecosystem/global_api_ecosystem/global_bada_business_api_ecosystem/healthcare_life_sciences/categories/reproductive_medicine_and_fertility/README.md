# Reproductive Medicine & Fertility

Category ID: `reproductive_medicine_and_fertility`

## Scope
Fertility clinics, IVF and assisted reproduction, reproductive endocrinology, fertility preservation and related clinical support.

## Subcategories
- `ivf_and_assisted_reproduction`
- `fertility_clinics`
- `reproductive_endocrinology`
- `fertility_preservation`

## Data and safety requirements
Clinical services require appropriately licensed providers, informed consent, transparent costs, medical privacy and applicable ART/surrogacy compliance. No guaranteed pregnancy claims.

Provider data must include source, verification status, jurisdiction, last-checked date and contact/credential details where lawful. This folder is a taxonomy scaffold; it does not establish live integrations or verified providers.
