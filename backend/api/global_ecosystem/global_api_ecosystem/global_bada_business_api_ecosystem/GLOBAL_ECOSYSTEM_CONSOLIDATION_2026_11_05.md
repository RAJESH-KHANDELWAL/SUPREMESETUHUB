# Global Ecosystem Consolidation — 2026-11-05

This change consolidates four requested folder groups in Global Bada Business.

1. `global_digital_infrastructure_telecommunications_technology_it_ai_business_api_ecosystem/`
   - Contains the related digital infrastructure, telecom, IT, software/AI/cloud, Apple, AWS, Google, IBM, Microsoft and Oracle packages.
2. `network_marketing_direct_selling_business_api_ecosystem/`
   - Remains the single Global + Bharat owner for network-marketing and direct-selling business models. Ordinary MSME/SME businesses remain in their respective business/enterprise domains.
3. `global_freelancer_gig_independent_work_business_api_ecosystem/`
   - Contains the freelance/gig taxonomy and the nested `jobs_careers_employment_api_ecosystem/` employment taxonomy.
4. `global_finance_banking_insurance_api_ecosystem/global_payment_business_api_ecosystem/`
   - Contains PayPal, Stripe, Epoch, Paxum, Segpay, Verotel and CCBill provider packages.

Related root-level duplicate folders were removed from the canonical Bada Business root. Imports, provider registry references, tests, workflow paths and taxonomy documentation were updated to the new ownership paths.

This is a taxonomy/package reorganization only. It does not establish live integrations, provider verification, regulatory approval or live job/payment availability.
