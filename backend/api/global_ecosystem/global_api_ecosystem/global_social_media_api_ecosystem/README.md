# Global Social Media API Ecosystem

India + global catalog of mainstream, professional, creator, publishing, community,
federated, social-commerce and age-restricted adult-creator platforms.

## Scope

The provider directory covers India-focused platforms alongside worldwide services.
It records category, region and a high-level API availability indicator. API status is
a discovery hint only and must be verified against current official provider
documentation before implementation.

## Structure

- `social_media_api_ecosystem.py` — provider directory, categories and filters.
- `integrations/` — integration metadata and integration service endpoints.
- `services/` — service-layer files.
- `tools/` — tool-layer files.
- `meta_social_media_api_ecosystem/` — Meta provider family.
- `x_social_media_api_ecosystem/` — X provider family.

## Compliance and safety

Use only official APIs, documented partner programs and user-authorized access.
Respect platform terms, app-review requirements, privacy, consent, retention and
rate limits. Adult-oriented entries are limited to lawful, consensual, age-restricted
platform metadata and compliant account integrations. This catalog does not provide
explicit media hosting, generation, scraping or distribution.

## Connectivity status

This is a catalog, not a universal live connector. Individual providers must be
implemented and tested independently. No platform-wide live connection is claimed.
