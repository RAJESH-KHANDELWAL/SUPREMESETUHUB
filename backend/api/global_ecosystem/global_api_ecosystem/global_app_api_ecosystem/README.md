# GLOBAL APP API ECOSYSTEM

Central catalog of application platforms and app lifecycle API providers.

## Scope

This category includes global consumer, creator, productivity, collaboration, design, commerce, developer, media, and business applications. This is a curated and expandable catalog—not a claim that every application in the world is listed.

## API and readiness policy

- Provider folders record the provider/category mapping and implementation status.
- CATALOG_ONLY means the provider is registered but a working adapter has not been verified.
- Official documentation, authentication requirements, rate limits, and permissions must be checked before implementing each integration.
- Live connectivity must not be claimed until a real API call is tested with valid credentials.
- Never commit API keys, OAuth secrets, access tokens, or customer data.

## Existing shared endpoint

- GET /global/app/status

Provider catalog and shared category folder are separate from provider-owned service implementations.
