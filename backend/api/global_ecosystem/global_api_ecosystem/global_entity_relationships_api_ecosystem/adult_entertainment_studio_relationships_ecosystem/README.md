# Adult Entertainment Studio Relationships Ecosystem

Catalog lawful 18+ production studios and their documented business relationships, licensing arrangements, distributors, hosting vendors and compliance providers. Verify legal identity, jurisdiction, age assurance, performer consent and rights ownership. No minors, coercion, trafficking or non-consensual material.

## Scope and maturity
This folder is a category scaffold for India and international entity relationships, from Normal and Standard through Advanced, Enterprise and Supreme maturity. Record stable source/target entity IDs, relationship type, jurisdiction, verification status and supporting source URLs. A catalog entry is not an endorsement, verified relationship or live API connection.
