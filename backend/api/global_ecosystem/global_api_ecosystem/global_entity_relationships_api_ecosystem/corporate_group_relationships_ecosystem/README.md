# Corporate Group Relationships Ecosystem

Map parent companies, subsidiaries, holding companies, sister concerns, joint ventures and controlled entities. Ownership/control claims require documentary evidence and review.

## Relationship data requirements
Each relationship record should include a stable ID, source and target entity IDs, relationship type, jurisdiction, verification status, effective dates where applicable, and source URLs for verified claims. Do not infer ownership, affiliation, consent, licensing or API access from a directory listing. This directory is a documentation scaffold; it does not create a live integration or assert real-world relationships.
