# Adult Content Distribution and Licensing Relationships Ecosystem

Map rights holders, authorized distributors, licensing agents, publishers and platforms for lawful 18+ content. Record territory, term, permitted use, takedown process and source documents. Exclude piracy and non-consensual distribution.

## Scope and maturity
This folder is a category scaffold for India and international entity relationships, from Normal and Standard through Advanced, Enterprise and Supreme maturity. Record stable source/target entity IDs, relationship type, jurisdiction, verification status and supporting source URLs. A catalog entry is not an endorsement, verified relationship or live API connection.
