# Adult Industry Relationship Taxonomy

This directory defines entity classifications and relationship mapping for lawful, consent-based 18+ services in India and international markets.

- dating_relationship_platform
- sexual_wellness_education_provider
- adult_platform_operator
- adult_creator_business

- consent_management_provider
- trust_safety_moderation_provider
- adult_industry_payment_provider
- creator_payout_provider
- privacy_security_vendor
- hosting_and_delivery_provider
- legal_compliance_provider

## Relationship mapping
Use only documented relationship types from the parent registry, including `operates`, `owns`, `provides_api_to`, `hosts_content_for`, `licenses_content_to`, `age_verifies_for`, `verifies_consent_for`, `moderates_for`, `processes_payments_for`, `handles_payouts_for` and `provides_safety_support_to`.

## India/global metadata
For each entity, record legal name, public website, jurisdiction, service regions, official developer documentation, API availability, age restrictions, privacy policy, content/consent policy and verification status.

Do not add unverified ownership claims or private personal data. Adult services must be 18+ and lawful in each served jurisdiction. Prohibit minors, non-consensual content, exploitation, trafficking and illegal material. This taxonomy is documentation only, not a live API integration.
