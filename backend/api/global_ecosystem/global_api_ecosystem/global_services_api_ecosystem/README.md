# GLOBAL SERVICES API ECOSYSTEM

Central home for service records and service-specific functionality across Bharat and the world.

## Endpoint
- `GET /global/services/status`

The matching `global_services_ecosystem/` folder and `global_services_ecosystem.py` entry module live together in this package. Companies, platforms, tools, and integrations are maintained in their own sibling GLOBAL API ECOSYSTEM packages, not duplicated here.
