# Domains, CDN & Media Delivery

## Scope
Domain/DNS services, CDN, video transcoding, media storage, origin protection and delivery optimization suitable under provider policies.

## Provider verification checklist
Confirm provider acceptable-use policy, content restrictions, API availability, regional performance, retention and lawful takedown support.

## Catalog rules
- Record official provider name, website, country/region availability, terms and documentation URL.
- Set status to `CATALOG_ONLY` until an official API/partner route is confirmed.
- Never infer live API access from a public website or marketing page.
- Add integrations only with permitted access, secure credentials, bounded requests, tests and clear error handling.
- Follow applicable laws, adult-only access, consent, privacy, copyright and platform terms.
