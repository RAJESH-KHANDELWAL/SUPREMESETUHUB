This is intentionally separate from GLOBAL AI API ECOSYSTEM: adult-industry providers may use AI, hosting, video, payments, creator tools, affiliate marketing, or compliance services, but those are distinct capability categories.

## Implementation status

The current provider entries are `CATALOG_ONLY`. A catalog entry does not prove a public API exists, that API access is permitted, or that authentication or live requests have been tested. Build a connector only against official documentation and permitted endpoints; use least-privilege credentials, secret storage, consent, safe error handling and automated tests. Do not store passwords, payment card data, identity documents, or explicit media in this catalog.

This package is not yet proof of a live integration or production-ready compliance system. Any future implementation must be limited to lawful adult services, adults-only access, verified consent, privacy protection and applicable platform/provider terms.
