## Purpose

This is the Cloudflare provider mapping under the shared GLOBAL ADULT INDUSTRY API ECOSYSTEM, following the same provider-to-category structure used by `cloudflare_ai_api_ecosystem`, `cloudflare_app_api_ecosystem`, and `cloudflare_cloud_api_ecosystem`.

It maps potentially relevant general Cloudflare products (DNS/zones, security/WAF/API Shield, SSL/TLS, R2, Stream/Images, Workers/Pages, and Analytics/Logpush). It does **not** claim Cloudflare has a dedicated adult-industry API or that any adult-industry provider is connected to Cloudflare.

## Integration gate

1. Verify the official API documentation, current terms, product availability, and account eligibility.
2. Use only product capabilities that are actually supported for the intended use.
3. Respect privacy, consent, age-gating, content licensing, and applicable law.
4. Store credentials in environment variables or a managed secret store; never commit secrets.
5. Add mocked unit tests and authenticated integration tests before marking any connection live.
