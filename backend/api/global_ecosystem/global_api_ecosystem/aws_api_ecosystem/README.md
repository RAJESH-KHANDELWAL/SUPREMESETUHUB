# AWS API ECOSYSTEM

Canonical provider catalog for AWS products and services.

The child folders below represent named AWS services and developer platforms. API capability families remain separately listed in `aws_api_ecosystem.py` and are not substituted for product/service names.

- Service entries: 37
- Catalog-only status: no live connection is asserted
- Credential strategy: IAM roles or managed secret storage

See each child README for the service boundary and implementation requirements.
