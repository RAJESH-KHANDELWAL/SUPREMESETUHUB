# AWS Company Provider Package

Provider-specific discovery and classification metadata only. This package does not prove legal registration, legal ownership, or a live connection to an official company registry.

- Provider ID: `aws`
- Existing metadata module: `aws_companies_api_ecosystem.py`
- Company verification requires jurisdiction-specific legal identity and traceable evidence.
- Product APIs and official websites are discovery sources, not automatically company-registration authorities.
- Platform ownership/operator relationships must use the shared `global_entity_relationships_api_ecosystem`, not duplicated company profiles.
