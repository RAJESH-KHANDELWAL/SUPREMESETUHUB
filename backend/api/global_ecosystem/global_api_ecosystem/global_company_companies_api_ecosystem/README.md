# GLOBAL COMPANY / COMPANIES API ECOSYSTEM

Unified, source-aware directory for registered companies, operating businesses and independent freelancers.

The architecture follows the Global Bada Business API Ecosystem pattern: root API and registries, class-specific domain packages, and separate industry, country and provider support modules. All classes share one normalized profile registry and search service.

See [GLOBAL_COVERAGE_AND_CLASSIFICATION.md](GLOBAL_COVERAGE_AND_CLASSIFICATION.md).

**Data status:** the local profile registry is currently empty. Country/provider metadata is not a live external connection.
