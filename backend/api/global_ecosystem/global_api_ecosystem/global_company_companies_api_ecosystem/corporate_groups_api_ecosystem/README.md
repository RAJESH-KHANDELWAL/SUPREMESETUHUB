# Corporate Groups

Distinct taxonomy for parent, holding, subsidiary and affiliated corporate structures. A corporate group is not interchangeable with one legal company or one operating enterprise.

Package contract: `DOMAIN_ID`, `DOMAIN_NAME`, `ADULT_RESTRICTED`, `DEFAULT_DISCOVERY_ENABLED`, `SUBCATEGORY_IDS`, `list_subcategories()`.

Taxonomy only. Group membership, control, ownership percentages and parent/subsidiary relationships require jurisdiction-aware sourced evidence. No live profile data or provider connection is implied. IDs must remain stable and lowercase snake_case.
