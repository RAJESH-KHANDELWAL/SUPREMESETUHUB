# India Developer Platform API Ecosystem

India-first provider catalog: government and public digital infrastructure where authorized, cloud and hosting, telecom, SMS/voice, email, maps, identity verification, commerce, logistics and developer tooling.

Tiers: Normal (public/sandbox), Standard (authenticated), Advanced (webhooks/automation), Enterprise (SLA/audit/residency), Supreme (multi-region resilience and governance).

Record provider, official docs URL, supported states/regions, data residency, pricing, authentication, rate limits, consent/legal basis and integration status. Do not assume access to Aadhaar, UPI or government systems; use approved rails and licensed partners only.
