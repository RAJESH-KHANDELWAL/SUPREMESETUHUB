# Payments and Billing API Ecosystem

Catalog India and global payment gateways, subscriptions, invoicing, tax calculation, payouts, fraud checks and reconciliation APIs.

India examples/categories include UPI-enabled licensed payment providers, cards and netbanking. Global categories include cards, wallets and bank transfers. Never store raw card data; use provider-hosted/tokenized flows, webhook signature validation, refunds and chargeback controls. Verify licensing and supported jurisdictions.
