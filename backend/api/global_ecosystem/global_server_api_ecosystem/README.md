# GLOBAL SERVER API ECOSYSTEM

This package provides the initial FastAPI routes and service status endpoint for the Global Server API Ecosystem.

## Endpoint
- `GET /global/server/status`

## Package modules
- `__init__.py` — package exports
- `routes.py` — FastAPI router
- `service.py` — service logic
- `schemas.py` — response schema definitions

Company, platform, tool, service, and integration catalogs are organized in their corresponding subdirectories.
