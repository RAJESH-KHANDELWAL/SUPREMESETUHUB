Apple child storage taxonomy partition for SUPREMESETUHUB.

This namespace classifies device backup and recovery metadata. It contains the shared `domains/`, `geography/` and `maturity_levels/` taxonomies. It is catalog scaffolding only, not evidence of a dedicated Apple storage API or live account connection.

Integration state: `NOT_CONFIGURED`. Verify product availability, account entitlements, documented interfaces, permissions, regional restrictions and authorized read/write behavior before marking any capability CONNECTED. Never commit credentials or personal data.
