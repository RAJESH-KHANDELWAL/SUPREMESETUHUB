## Storage responsibility

## Security boundary
Use least privilege, approved secret management, encryption, controlled access, audit trails and safe retention. Do not commit credentials, private keys, passwords, exploit payloads, sensitive production logs or personal data.

Any implementation requires authorized credentials, security review, tests and live health verification.
