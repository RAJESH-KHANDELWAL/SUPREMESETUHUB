# GLOBAL_COMMUNICATION Storage Ecosystem

Communication storage taxonomy and foundation. Each category is an independent direct-child package in this directory; there are no generic `categories/` or `providers/` nesting layers.

## Ownership

This storage namespace owns category identity, metadata, schemas, lifecycle definitions and storage-health metadata. Provider authentication, API clients and external operations remain in their respective integration layers.

## Readiness

All categories start as `NOT_CONFIGURED`. Provider product support, account entitlement, authorized connectivity and working upload/download/delete operations are not implied. Never commit credentials or personal data.
