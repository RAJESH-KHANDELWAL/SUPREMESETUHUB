# ANTHROPIC Ecosystem

Canonical Anthropic provider namespace for SUPREMESETUHUB.

## Canonical hierarchy

`ANTHROPIC / WHAT ANTHROPIC PROVIDES / STORAGE ECOSYSTEM`

- `manifest.json`: provider identity, canonical path and compatibility mapping.
- `what_anthropic_provides/manifest.json`: provider-offerings catalog.
- `what_anthropic_provides/storage_ecosystem/`: canonical storage taxonomy and category packages.

The previous `anthropic_storage_ecosystem/` path is retained as a compatibility location; do not delete it while existing imports or references may depend on it.
