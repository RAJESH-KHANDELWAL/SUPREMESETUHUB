# GOOGLE Storage Ecosystem

Parent namespace for 184 independent Google-related storage category packages.

- `taxonomy/google_storage_taxonomy.json`: canonical category taxonomy.
- `category_index.json`: all 184 category folder names and paths.
- Each category folder contains its own Python package files, PHP metadata class, API namespace, models, schema, tests, README and manifest.

These are category-specific scaffolds, not 184 official Google products. Each is marked `NOT_CONFIGURED`; no live provider integration or storage operation is claimed. Official API support, authorized credentials, live health checks and end-to-end tests are required before enabling any integration.

Adult-related entries are classification namespaces only. Enforce age/access restrictions, consent, privacy and applicable law. Unlawful or exploitative content is prohibited.
