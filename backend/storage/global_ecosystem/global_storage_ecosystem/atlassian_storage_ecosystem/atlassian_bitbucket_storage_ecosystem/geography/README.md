# Bitbucket Geography Taxonomy

- `bharat/`: India, including state, union-territory, district, city, town and village references.
- `regional/`: South Asia and other recognized world regions.
- `global/`: country and worldwide jurisdiction references.

Atlassian cloud/data residency availability, tenant location, plan eligibility, regional service restrictions, contractual terms and legal permissions must be verified for the specific tenant. Geographic labels do not prove product availability or data residency.
