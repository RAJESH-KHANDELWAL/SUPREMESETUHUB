# Confluence Domain Taxonomy

This directory classifies business and personal-use contexts in which Confluence metadata may be organized, such as software development, project management, IT operations, customer support, knowledge management, product discovery, collaboration, education, finance, legal, government and other applicable organizational domains.

Domain labels are organizational metadata only. They do not grant access to tenant data or authorize collection, processing, export, storage or distribution. Apply privacy, confidentiality, consent, retention and jurisdiction-specific controls.
