# Jira Storage Ecosystem

Issues, projects, workflows, attachments and project metadata.

This product package is a catalog entry only. It does not imply live Atlassian API connectivity, account entitlement, export rights or provider-side storage guarantees.

Authentication, OAuth scopes, API clients and Jira operations belong in the separate Atlassian API/integration layer. Mark Jira connected only after authorized authentication, least-privilege permission checks, live health checks and end-to-end tests pass.
