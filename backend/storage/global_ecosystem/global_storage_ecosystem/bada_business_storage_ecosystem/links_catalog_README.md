## Verification boundary
These entries were already recorded in the repository's Bada Business resource files and have been organized into this storage ecosystem. This commit does not perform live URL checks. A stored URL does not establish that the destination is currently active, that a referral code is valid, that a course is accessible under the user's account, or that the provider has authorized an integration.

## Data rules
1. Preserve exact titles, course IDs, URLs and referral parameters.
2. Keep platform destinations separate from Community course destinations.
3. Do not download, mirror, scrape or redistribute protected course material.
4. Never store passwords, OTPs, session cookies, API keys or other credentials.
5. Record future URL checks with date, method and result; do not silently label unverified URLs as active.
