# WHAT GOOGLE PROVIDES

This package groups Google's provider offerings by ecosystem responsibility. The current canonical branch contains the Storage Ecosystem. API integrations remain in the dedicated backend API layer and are referenced rather than copied here.

## Included
- `storage_ecosystem/` — Google storage products, storage taxonomy, metadata foundation and lifecycle contracts.

## Boundary
Catalog entries do not imply product entitlement, regional availability, live authentication or successful object operations. Verify provider documentation, account permissions, location and policy before enabling a connector.
