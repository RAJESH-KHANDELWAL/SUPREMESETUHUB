# Universal Services Catalog

Catalog all lawful service types from local Bharat providers to international service networks.

## Service families
- Technology: software development, IT support, cloud, hosting, storage, databases, cybersecurity, AI, APIs, maintenance and consulting.
- Business: accounting, legal, tax, HR, marketing, sales, design, operations, procurement, logistics and professional advisory.
- Public and community: civic services, education, healthcare information, social support, nonprofit and public utilities.
- Consumer and lifestyle: home services, repairs, mobility, travel, hospitality, food, fitness, wellness and personal care.
- Media and creative: design, publishing, production, photography, video, audio, events and content services.
- Adult-only lawful services: age-restricted sexual wellness education and consenting-adult services only where lawful; apply strict age, consent, privacy and safety controls.

Each service record should include provider, offering, location/jurisdiction, eligibility, pricing model, terms, service hours, support channel, SLA, accessibility, verification state, required permissions and complaint/takedown route.

Lifecycle: discover → verify → compare → onboard → configure → deliver → monitor → support → bill/renew → migrate/close.
