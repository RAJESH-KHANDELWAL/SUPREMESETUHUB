# Universal Platforms Catalog

Catalog platforms as distinct entities, not as generic folders.

## Platform families
- Cloud, hosting, storage, compute, networking and data platforms.
- AI, developer, code-hosting, API, automation and collaboration platforms.
- Operating systems, software distribution, app stores and device ecosystems.
- Social media, messaging, communication, publishing and creator platforms.
- Commerce, marketplaces, payments, banking and financial technology platforms.
- Education, research, healthcare and public-service platforms.
- Media, streaming, gaming, sports and entertainment platforms.
- Travel, mobility, property, logistics and industrial platforms.
- Community, nonprofit and lawful adult-only platforms, with age and jurisdiction controls.

Track platform owner, official URL, product scope, supported countries, terms, API availability, data controller/processor role, interoperability, account requirements, pricing, security posture, status and last verification date. A catalog entry does not imply endorsement or connection.
