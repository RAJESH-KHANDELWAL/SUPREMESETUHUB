# Adobe Storage Domains

This folder classifies **Adobe-specific asset and storage workflows**, not universal human/business subject categories. Universal domains (including adult industry, sexual wellness, education, business, healthcare, culture, and government) belong to sibling Global Category Storage Ecosystems at the parent Global Storage layer.

Adobe workflow domains:
- Creative assets and design files
- Document workflows
- Photo and video assets
- Enterprise digital asset management
- Media review and collaboration
- Cross-product asset workflows

A subject category being stored as a file does not make it an Adobe storage product domain.
