# Universal Projects and Programs Catalog

Catalog personal, community, nonprofit, commercial, public-sector, research, construction, technology, creative and international projects.

Required project structure: project ID; title; owner/sponsor; domain; geography; maturity target; objective; scope; stakeholders; team and roles; budget/currency; funding; schedule; milestones; dependencies; risks; deliverables; approvals; legal/IP rights; security/privacy classification; status; metrics; change history; closure and archival plan.

Support programs, portfolios, campaigns, initiatives, research studies, events and workstreams as related but distinct entity types. Project registration does not imply funding, approval or execution.
