# Universal Resources and Assets Catalog

Catalog digital and physical resources: files, documents, images, audio, video, datasets, knowledge bases, code, domains, intellectual property, equipment, facilities, land, vehicles, inventory and infrastructure.

Track owner/custodian, source, rights/license, classification, location, format, checksum where applicable, storage provider, access policy, retention, backup state, lifecycle, provenance and audit history. Sensitive and adult media require additional consent, rights, age and access controls. Folder presence does not mean an asset exists or is stored.
