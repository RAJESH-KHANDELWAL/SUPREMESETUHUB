# Universal Organizations Catalog

Catalog companies, brands, partnerships, sole proprietors, startups, corporations, NGOs, trusts, societies, cooperatives, educational institutions, hospitals, government bodies, agencies, international institutions, clubs and community groups.

Track legal identity separately from brand identity. Include jurisdiction, registration evidence, parent/subsidiary relationships, official contacts, authorized representatives, locations, industry, services, products, projects, licenses, compliance state, ownership disclosures where lawful, verification source and last review date. Do not infer legal status from a name or social profile.
