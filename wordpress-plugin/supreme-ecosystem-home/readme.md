# SUPREME ECOSYSTEM Home

Responsive homepage/portal shortcode for WordPress.

## Install
Upload the packaged ZIP in **WordPress Admin → Plugins → Add New Plugin → Upload Plugin**, install and activate.

## Use
Create or edit a WordPress page named **SUPREME ECOSYSTEM** and place this shortcode in a Shortcode block:

```
[supreme_ecosystem_home]
```

Optional destinations can be changed with shortcode attributes:

```
[supreme_ecosystem_home pod_url="/print-on-demand/" digital_url="/digital-store/" services_url="/services/" about_url="/about/"]
```

Create the destination pages in WordPress so the links resolve. The homepage does not represent checkout or fulfilment as live unless those systems have separately been configured and tested.
