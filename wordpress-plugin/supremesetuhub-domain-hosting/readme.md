# SUPREMESETUHUB Domain & Hosting

A WordPress plugin that displays the public, read-only SUPREMESETUHUB domain and hosting service catalogue.

## Requirements
- WordPress 6.2 or later
- PHP 7.4 or later
- HTTPS access to the backend public domain-hosting catalogue endpoint

## Setup
1. Install and activate the plugin.
2. Open **Settings → SUPREMESETUHUB Domain & Hosting**.
3. Configure the HTTPS backend base URL.
4. Add `[supremesetuhub_domain_hosting]` to a WordPress page.

The plugin does not store provider passwords or API keys. Catalogue display is read-only.
