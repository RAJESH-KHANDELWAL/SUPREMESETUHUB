# ATLASSIAN KNOWLEDGE AND COLLABORATION CORE ECOSYSTEM

**Parent:** ATLASSIAN CORE ECOSYSTEM

**Domain ID:** `KNOWLEDGE_AND_COLLABORATION`

**Purpose:** Confluence spaces, pages, content discovery, permissions and collaboration metadata.
