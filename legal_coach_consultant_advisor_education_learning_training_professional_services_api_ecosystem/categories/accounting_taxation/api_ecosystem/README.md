# Accounting & Taxation — API Ecosystem

Category ID: `accounting_taxation`  
Canonical owner: `professional_legal_business_services`

This page defines the category's API boundary and navigation metadata only. The implemented category catalog and routes remain owned by the canonical Professional, Legal & Business Services package.

## Minimum future data contract

- Stable category and provider identifiers
- Provider legal name and service description
- Service jurisdiction and delivery mode
- Original source URL and source type
- Credential or accreditation evidence, issuing authority and scope, where applicable
- Verification status, verifier and last-verified timestamp
- Listing status, consent and moderation history

## Safety and accuracy

Never infer a professional licence, bar membership, CA/CS status, accreditation, statutory authority or regulatory approval from a profile description. Show credential claims as unverified until checked against the relevant official register or issuing body. Do not present taxonomy entries as live providers or legal advice.
