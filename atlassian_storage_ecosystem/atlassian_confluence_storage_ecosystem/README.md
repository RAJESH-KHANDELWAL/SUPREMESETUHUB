# Confluence Storage Ecosystem

Pages, spaces, attachments, whiteboards and knowledge-content metadata.

This product package is a catalog entry only. It does not imply live Atlassian API connectivity, account entitlement, export rights or provider-side storage guarantees.

Authentication, OAuth scopes, API clients and Confluence operations belong in the separate Atlassian API/integration layer. Mark Confluence connected only after authorized authentication, least-privilege permission checks, live health checks and end-to-end tests pass.
