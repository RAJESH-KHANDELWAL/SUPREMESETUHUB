# Anthropic Domain Taxonomy

Shared provider-neutral domain classification for each Anthropic child ecosystem. Scope includes technology, business, finance, education, science, healthcare, health and wellness, culture, religion, agriculture, environment, government, law, media, entertainment, sports, travel and tourism, relationships, family, marriage, intimacy, sexual health and sexual education.

The `adult_only/` branch includes lawful adult relationships, intimacy, sexual wellness, adult sexual content, adult entertainment, lawful adult media and pornography classification. Require age assurance, informed consent, privacy/security controls and jurisdiction-specific legal review. Prohibit minors, coercion, exploitation and non-consensual intimate imagery.

These folders classify scope only; they do not authorize hosting, generation, storage or distribution.
