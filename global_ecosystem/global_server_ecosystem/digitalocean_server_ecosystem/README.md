# DIGITALOCEAN SERVER ECOSYSTEM

Canonical provider namespace for DigitalOcean within SUPREMESETUHUB GLOBAL SERVER.

- Provider identity: `digitalocean`
- Existing adapter compatibility package: `../digitalocean_server/`
- Service-family namespaces are catalog/contract boundaries, not proof of provider support or live connectivity.
- Provider-specific handlers must be explicitly configured and validate provider capabilities, credentials, authorization, and operation payloads.

## Service-family namespaces

- `digitalocean_vpn_server_ecosystem/` — VPN SERVER (vpn-server)
- `digitalocean_vps_server_ecosystem/` — VPS SERVER (vps-server)
- `digitalocean_cloud_server_ecosystem/` — CLOUD SERVER (cloud-server)
- `digitalocean_web_server_ecosystem/` — WEB SERVER (web-server)
- `digitalocean_cloud_web_server_ecosystem/` — CLOUD WEB SERVER (cloud-web-server)
- `digitalocean_dedicated_server_ecosystem/` — DEDICATED SERVER (dedicated-server)
- `digitalocean_edge_server_ecosystem/` — EDGE SERVER (edge-server)
- `digitalocean_application_server_ecosystem/` — APPLICATION SERVER (application-server)
- `digitalocean_database_server_ecosystem/` — DATABASE SERVER (database-server)
