# Adobe Express — Core Ecosystem

Template-based design, social content, quick video and document creation.

Core owns identity, capability metadata, lifecycle, policy and readiness. API transport/OAuth belongs to API; persistence belongs to Storage/Database; jobs belong to Runtime/Engine; user journeys belong to Application/UI.

This is a documented Core scaffold, not a live integration. Product-specific capability definitions, API entitlement checks and integration tests remain pending.
