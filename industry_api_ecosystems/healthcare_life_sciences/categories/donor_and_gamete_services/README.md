# Donor & Gamete Services

Category ID: `donor_and_gamete_services`

## Scope
Lawful sperm/egg donor programmes, regulated gamete banks, donor screening, recipient counselling and related clinical coordination.

## Subcategories
- `sperm_donor_programmes`
- `egg_donor_programmes`
- `gamete_banks`
- `donor_screening_and_counselling`

## Data and safety requirements
Assume 'spam donor' meant 'sperm donor'. Include only lawful, appropriately regulated services. Protect donor/recipient identity and health data; require informed consent, screening, traceability and jurisdiction checks. No informal or unverified matching.

Provider data must include source, verification status, jurisdiction, last-checked date and contact/credential details where lawful. This folder is a taxonomy scaffold; it does not establish live integrations or verified providers.
