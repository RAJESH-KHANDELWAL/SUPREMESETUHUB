# Gym & Fitness Centres

Category ID: `gym_and_fitness_centres`

## Scope
Fitness facilities, studios and group training. Verify business registration, trainer qualifications, safety practices and facility details.

## Subcategories
- `gyms`
- `fitness_studios`
- `strength_training`
- `group_fitness`

Provider records must include source, jurisdiction, verification status and last-checked date. This is documentation, not a verified provider directory.
