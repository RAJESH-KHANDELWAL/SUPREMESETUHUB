# SUPREME COLLABORATION GO-LIVE CHECKLIST

Use one copy per partner/integration. Do not launch while a mandatory item is incomplete.

## A. Counterparty
- [ ] Unique collaboration ID assigned
- [ ] Partner legal identity and official domain independently checked
- [ ] Signatory authority confirmed
- [ ] Purpose, outcomes, scope and exclusions written down
- [ ] Fraud/scam checks complete; no unexplained upfront registration/release fee

## B. Mutual benefit
- [ ] Deliverables, owners, dates, acceptance criteria and support documented
- [ ] Model selected: percentage / per eligible order / tiered / referral / fixed fee / in-kind / hybrid
- [ ] Exact rate/amount, currency and eligible base/event completed
- [ ] Attribution method/window and conflicting/duplicate referrals addressed
- [ ] Taxes, fees, discounts, shipping, refunds, cancellations, chargebacks and rounding defined
- [ ] Payout threshold, schedule, invoice requirements and evidence defined
- [ ] Caps, minimums, tier boundaries and post-termination events addressed
- [ ] Both parties approve the same final agreement version

## C. Permissions and privacy
- [ ] Contact permission recorded
- [ ] Name/logo/public announcement separately approved
- [ ] Provider connection and exact API scopes approved
- [ ] Data fields, purpose, notices/consent, access, retention and deletion documented
- [ ] Secrets stored in approved secret storage, never source control
- [ ] Provider terms and applicable legal requirements reviewed

## D. Documents and records
- [ ] Agreement/schedules reviewed by qualified counsel where appropriate
- [ ] Signed/accepted PDF and editable version stored with restricted access
- [ ] Agreement ID/version, signatory identity, timestamps and evidence references recorded
- [ ] Both parties received copies
- [ ] Change-control and dispute contacts confirmed
- [ ] Backup/restore and authorized access verified

## E. Technical tests
- [ ] Least-privilege access configured by authorized operator
- [ ] Sandbox/test events used where available
- [ ] Duplicate webhook/event and idempotency tests passed
- [ ] Order/referral attribution test passed
- [ ] Cancellation, partial/full refund and chargeback cases tested as applicable
- [ ] Benefit calculation reconciled with source records
- [ ] Access-denied and permission-revocation tests passed
- [ ] Logs do not expose secrets or unnecessary personal data
- [ ] Monitoring, incident contact and rollback/offboarding ready

## F. Dual approval
- [ ] First party go-live approval: name, role, timestamp and evidence
- [ ] Partner go-live approval: name, role, timestamp and evidence
- [ ] Go-live date/time/timezone recorded
- [ ] First reconciliation date and owner assigned

## G. After launch and closure
- [ ] Reconciliation cadence and owner assigned
- [ ] Dispute window and response owner assigned
- [ ] Access review date assigned
- [ ] Termination, token revocation, data handling and final settlement planned
