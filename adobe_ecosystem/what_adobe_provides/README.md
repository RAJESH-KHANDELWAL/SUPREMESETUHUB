# What Adobe Provides

This directory catalogs Adobe product and service families, then groups provider storage capabilities under storage_ecosystem/.

- Creative Cloud: creative desktop, web and mobile applications and services.
- Document Cloud: Acrobat, Reader, Acrobat Sign and document workflows.
- Experience Cloud: Experience Manager, data, analytics, journey and marketing products.
- Firefly and AI: generative creative services and enterprise AI capabilities.
- Express and design: fast content creation and templates.
- Video collaboration: Frame.io and media review/collaboration.
- Work management: Workfront and work management services.
- Commerce: Adobe Commerce and related commerce products.
- Publishing and community: Fonts, Stock, Behance, Portfolio and publishing/learning products.

Product availability does not imply that a product exposes a public storage API. Each adapter must be verified against official API documentation and account entitlements.
