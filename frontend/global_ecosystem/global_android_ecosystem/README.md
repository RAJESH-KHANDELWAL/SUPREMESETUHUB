# Frontend Global Android Ecosystem

Frontend-owned Android experience and integration surfaces.

## Scope
- Responsive web/front-end interfaces that integrate with Android ecosystem capabilities.
- Client-side contracts, deep-link/navigation integration, and presentation logic where applicable.
- Coordinate with the separate top-level `android/` application source tree.

## Boundaries
- Native Android application code belongs in `android/`, not in this frontend package.
- Backend APIs and authorization decisions remain backend-owned.
- Do not duplicate native screens or services here.
