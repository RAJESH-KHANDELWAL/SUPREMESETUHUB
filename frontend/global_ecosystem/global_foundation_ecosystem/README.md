# Frontend Global Foundation Ecosystem

Shared frontend foundations used across product and domain experiences.

## Scope
- Shared UI contracts, reusable presentation primitives, application composition, and frontend-wide conventions.
- Define reusable foundations without coupling them to a single business domain.

## Boundaries
- Coordinate with existing `frontend/foundation` modules; do not duplicate managers or components.
- Preserve existing routes, asset paths, and build entry points until a migration is separately tested.
