# SUPREME HOME — Fluent Snippets setup

This folder stores the three separated WordPress Fluent Snippets sources for the SUPREME homepage.

## 1. 🏡 HOME 🏡 HTML
File: `home-html.html`

Create/edit the Fluent Snippets HTML/PHP Content snippet, configured to run as a shortcode. Use only the container from that file. The shortcode generated by Fluent Snippets belongs in the WordPress Home page content. Do not guess a shortcode ID.

## 2. 🏡 HOME 🏡 CSS
File: `home-css.css`

Create/edit the Fluent Snippets CSS snippet and paste this CSS import. It loads the canonical stylesheet from this repository.

## 3. 🏡 HOME 🏡 JS
File: `home-js.js`

Create/edit a separate JavaScript snippet and paste the JavaScript body (omit the descriptive comment if the editor requires plain JS). The loader fetches `../index.html` from this repository, inserts its body into `#GITHUB-HOME-CONTENT`, and re-executes its inline scripts.

## Canonical source files

- Homepage content: `frontend/supreme/index.html`
- Homepage CSS: `frontend/supreme/style.css`
- Homepage loader JS: `frontend/supreme/index.js`

Do not use `frontend/index.html` for SUPREME. That file is reserved for LINKSETU.

## Important

The GitHub repository can store the snippets, but it cannot by itself update snippets inside the live WordPress admin. Paste these files into Fluent Snippets, then place the shortcode generated by that plugin on the WordPress Home page.
