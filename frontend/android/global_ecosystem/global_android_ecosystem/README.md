# Frontend Global Android Ecosystem

Frontend-owned Android UI, navigation, presentation, client state, and app-side integrations belong here.

- Frontend root: `frontend/android/`
- Ecosystem entry point: `frontend/android/global_ecosystem/global_android_ecosystem/`
- Manager: `manager.py`

This is an independent Android namespace, not a Foundation or Infrastructure child. The structure does not claim that a native Android app or release build is complete.
