# GLOBAL WORDPRESS ECOSYSTEM — FRONTEND

This directory is the frontend home for the global WordPress ecosystem.

## Scope

- WordPress ecosystem interface and status views
- Registered-site visibility and connection status
- Owner-facing controls that call the authenticated backend API
- Frontend assets and components specific to the WordPress ecosystem

The frontend must use the backend API as its integration boundary. It must
not connect directly to WordPress databases or expose credentials.

No existing frontend files were moved or overwritten as part of this
foundation setup.
