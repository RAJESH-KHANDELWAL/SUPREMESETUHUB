# Frontend Global iOS Ecosystem

This namespace is the Frontend-wide iOS entry point for native UI, navigation, presentation, and client-side features.

## Ownership boundaries

- Frontend iOS: screens, UI composition, navigation, state and client-side presentation.
- Backend iOS: server-side APIs, service contracts and backend integrations.
- Backend Foundation iOS: canonical native project contract.
- Backend Infrastructure iOS: build/runtime, CI and deployment operations.

The frontend namespace does not duplicate the canonical native iOS project or claim a verified Xcode build.
