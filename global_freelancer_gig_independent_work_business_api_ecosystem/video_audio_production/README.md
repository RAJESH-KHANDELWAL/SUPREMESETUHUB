# Video Audio Production

## Scope
Video, motion, podcast and audio editing and production services.

## Independent work catalogue
This specialization owns its work-type catalogue in `work_types.py`. Each work type has a stable ID, a clear deliverable-oriented name and an explicit scope. The package exposes its own model, catalogue, service facade, API router, schema, validator and tests.

## Work types
1. **Short-form video editing** — Short-form video editing.
2. **Long-form video editing** — Long-form video editing.
3. **Motion graphics and animation** — Motion graphics and animation.
4. **Podcast editing** — Podcast editing.
5. **Audio cleanup and mastering** — Audio cleanup and mastering.
6. **Subtitles and captions** — Subtitles and captions.

## Boundaries
This package defines service and work classifications only. It does not claim that a gig, vacancy, client, provider, payment or licence is live or verified. Legal, accounting, transport, electrical and other regulated services must comply with the applicable jurisdiction and professional authorization requirements.
